## 问题

年底盘点靠 Excel 一台台登记：谁在用哪台电脑、序列号多少、什么时候过保，表格永远和实际对不上。

## 适用场景

- 适合：电脑几十台以上、靠 Excel 登记资产、每年盘点很痛苦的公司
- 不值得：已经有 Intune、SCCM 或商业资产管理软件的
- 前提：电脑加入了域（能下发组策略），或能统一运行脚本

## 工具选型

| 方案                      | 特点                 | 适用        |
| ------------------------- | -------------------- | ----------- |
| PowerShell + GPO 开机脚本 | 零成本，不装客户端   | ✅ 方案采用 |
| Snipe-IT                  | 开源资产管理系统     | 国内外都用  |
| GLPI + 代理               | 开源 ITSM + 自动盘点 | 欧洲常用    |
| Intune / SCCM             | 微软终端管理         | 外企常用    |

脚本采集 + 汇总表：小公司零成本先把数据自动化；数据进 Snipe-IT 后还能管理领用、借还。

## 怎么做

- 用组策略下发开机脚本，PowerShell 通过 CIM 采集主机名、型号、序列号、CPU、内存、硬盘、系统版本、已装软件、最后登录用户
- 每台电脑写一个 JSON 到共享目录（或 POST 到内部接口），不需要装客户端
- Python 每天汇总成 Excel：按部门分组，标出过保、内存小于 8G、系统已停止支持、装了未授权软件的机器
- 盘点时只需核对标出来的少数异常

## 实施步骤

| 步骤 | 做什么                                  | 怎么验证                          |
| ---- | --------------------------------------- | --------------------------------- |
| 1    | 写采集脚本，本机测试                    | 输出包含序列号、内存等字段的 JSON |
| 2    | 建共享目录，只给电脑写入、IT 读取的权限 | 普通员工看不到别人的文件          |
| 3    | 组策略下发开机脚本                      | 第二天共享目录里出现各电脑的文件  |
| 4    | Python 汇总成 Excel，标出异常           | 过保、低配、旧系统都被标出        |
| 5    | 盘点时只核对异常项                      | 盘点用时明显缩短                  |

## 关键代码

示例代码（简化），没有在生产环境运行：

```powershell
$info = [ordered]@{
  host   = $env:COMPUTERNAME
  user   = (Get-CimInstance Win32_ComputerSystem).UserName
  model  = (Get-CimInstance Win32_ComputerSystem).Model
  serial = (Get-CimInstance Win32_BIOS).SerialNumber
  memGB  = [math]::Round((Get-CimInstance Win32_ComputerSystem).TotalPhysicalMemory / 1GB)
  os     = (Get-CimInstance Win32_OperatingSystem).Caption
}
$info | ConvertTo-Json | Set-Content "\\fs01\assets$\$env:COMPUTERNAME.json"
```

| 指标         | 做之前       | 预期效果（估算） |
| ------------ | ------------ | ---------------- |
| 年底盘点     | 几天（估算） | 半天             |
| 资产表准确性 | 和实际对不上 | 每天自动更新     |
| 换机决策     | 凭感觉       | 按配置和保修数据 |

资产表每天自动更新，盘点从几天变成半天；采购时有数据说明哪些电脑该换了。

## 常见坑

- **笔记本长期不在公司，数据不更新**：开机脚本只在域网络内能写共享目录。改用 HTTPS 上报接口，VPN 连接时也能上报。
- **序列号为空或是默认值**：组装机或部分品牌机。用主板序列号、MAC 地址辅助识别。
- **采集脚本被执行策略拦截**：PowerShell 执行策略。组策略里设置执行策略或对脚本签名。

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会用组策略给所有电脑下发开机脚本，PowerShell 通过 CIM 采集主机名、型号、序列号、CPU、内存、硬盘、系统版本、已装软件和最后登录用户，每台写一个 JSON 到共享目录，不需要装客户端。Python 每天汇总成 Excel，按部门分组，标出过保、内存小于 8G、系统已停止支持的机器，年底盘点只核对这些异常。

常见追问：

**问：为什么用 CIM 而不是 WMI 命令？**

答：Get-CimInstance 是新的接口，基于 WS-Man，远程查询更稳定；Get-WmiObject 在 PowerShell 7 里已经移除。

**问：资产管理要管哪些信息？**

答：设备信息、使用人、位置、采购日期、保修、状态（在用、库存、维修、报废）。

**问：如何发现没加域的电脑？**

答：对比 DHCP 租约、交换机 MAC 地址表和资产表，找出不在资产表里的设备。

**被问到「能不能用 AI」时：** 资产盘点靠采集，不需要 AI。
