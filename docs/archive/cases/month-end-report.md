## 问题

每月关账后财务要花两三天从系统导数、在 Excel 里重新分类、做透视表、写说明，报表出来时已经是下个月中旬。

## 适用场景

- 适合：有月度管理报表需求、科目和部门较多的公司
- 不值得：业务简单、财务软件自带报表就够的
- 前提：ERP 能导出科目余额和明细

## 工具选型

| 方案                      | 特点             | 适用                     |
| ------------------------- | ---------------- | ------------------------ |
| ERP 自带报表              | 标准报表         | 国内外都有               |
| Python + Excel 模板       | 管理口径灵活     | ✅ 方案采用              |
| BI 工具（帆软、Power BI） | 可视化、可钻取   | 国内帆软 / 外企 Power BI |
| Excel Power Query         | 财务人员自己维护 | 常用                     |

标准财务报表用 ERP；管理口径的重分类和分析用脚本或 BI。

## 怎么做

- 关账后从 ERP 取科目余额和明细，按管理口径重分类（如把费用按部门、项目归集）
- 生成利润表、费用明细、部门预算执行对比，计算环比和同比
- 变动超过 20% 的项目自动标出，并列出主要的明细凭证，方便写说明
- 用公司的 Excel 模板输出，格式不变

## 实施步骤

| 步骤 | 做什么                     | 怎么验证           |
| ---- | -------------------------- | ------------------ |
| 1    | 整理科目到管理口径的映射表 | 财务确认           |
| 2    | 从 ERP 取数                | 余额和系统一致     |
| 3    | 生成报表和对比             | 和手工报表核对一致 |
| 4    | 标注异常并列出明细         | 异常项有凭证可查   |
| 5    | 关账后自动运行并发送       | 当天出报表         |

## 常见坑

- **新增科目没有映射**：科目表变了。未映射的科目单独列出，不能静默丢掉。
- **口径变化导致历史不可比**：映射表改了。映射表版本化，口径变化时重算历史。
- **跨期调整**：关账后又有调整凭证。以关账时点取数，调整单独说明。

常见追问：

**问：财务报表和管理报表的区别？**

答：财务报表按会计准则对外披露；管理报表按管理需要的口径（部门、项目、产品）对内分析。

**问：科目余额表是什么？**

答：每个会计科目的期初、发生额、期末余额，是出报表的基础。

**问：怎么保证自动报表的数字正确？**

答：和系统标准报表核对总数，映射表有人维护，未映射科目报警。

**被问到「能不能用 AI」时：** 月结数字必须精确，AI 帮写变动分析的初稿。
