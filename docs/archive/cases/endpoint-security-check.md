## 问题

电脑丢了里面全是客户资料、杀毒软件被员工关了、病毒库半年没更新——这些风险在出事前没人知道。

## 适用场景

- 适合：员工电脑几十台以上、有客户数据或审计要求的公司
- 不值得：已经有统一终端管理（EDR、Intune）报表的
- 前提：电脑加入域或 Intune 管理

## 工具选型

| 方案                      | 特点                     | 适用        |
| ------------------------- | ------------------------ | ----------- |
| PowerShell 自写采集       | 零成本，复用资产盘点通道 | ✅ 方案采用 |
| Microsoft Intune 合规策略 | 设备不合规可阻止访问     | 外企常用    |
| 奇安信、深信服终端安全    | 国产 EDR 套件            | 国内常用    |
| Wazuh                     | 开源安全监控，含终端合规 | 开源        |

自写采集：没有 Intune 或 EDR 的小公司零成本就能看到风险；有了再用平台自带的合规报表。

## 怎么做

- 复用资产盘点的上报通道，PowerShell 额外采集：Defender 是否开启、病毒库更新时间、Windows 防火墙状态、BitLocker 加密状态、本地管理员组成员
- 汇总成合规表：病毒库超过 7 天未更新、防火墙关闭、笔记本未加密、员工在本地管理员组里，都算不合规
- 不合规项提醒本人并抄送 IT，连续一周未处理升级给主管
- 能自动修复的（开启防火墙、更新病毒库）用组策略或 Intune 直接下发

## 实施步骤

| 步骤 | 做什么                                             | 怎么验证             |
| ---- | -------------------------------------------------- | -------------------- |

## 关键代码

示例代码（简化），没有在生产环境运行：

```powershell
$mp = Get-MpComputerStatus
[pscustomobject]@{
  Host        = $env:COMPUTERNAME
  AV          = $mp.AntivirusEnabled
  SigAgeDays  = $mp.AntivirusSignatureAge
  Firewall    = (Get-NetFirewallProfile | Where-Object Enabled -eq $false).Count -eq 0
  BitLocker   = (Get-BitLockerVolume -MountPoint C:).ProtectionStatus -eq 'On'
  LocalAdmins = (Get-LocalGroupMember Administrators).Name -join ';'
}
```

## 常见坑

- **BitLocker 恢复密钥丢失**：加密时没备份密钥。加密前把恢复密钥备份到 AD 或 Entra ID。
- **员工是本地管理员，自己关掉杀毒**：权限过大。收回本地管理员，用 LAPS 管理本地管理员密码。
- **采集脚本被安全软件拦截**：PowerShell 执行策略或 EDR 规则。脚本签名，或在安全软件里加白名单。

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会复用资产盘点的上报通道，用 PowerShell 额外采集每台电脑的 Defender 状态、病毒库更新时间、防火墙、BitLocker 加密状态和本地管理员组成员，汇总成合规表：病毒库超过 7 天、防火墙关闭、笔记本未加密、员工是本地管理员都算不合规，提醒本人并抄送 IT。能自动修复的用组策略下发。

常见追问：

**问：为什么员工不应该是本地管理员？**

答：可以安装任意软件、关闭安全防护，恶意软件也能获得管理员权限；用 LAPS 管理本地管理员密码。

**问：BitLocker 有什么用？**

答：磁盘加密，电脑丢失时别人无法读取数据；恢复密钥要备份到 AD。

**问：EDR 和传统杀毒软件的区别？**

答：杀毒软件靠特征码查杀；EDR 持续记录终端行为，能发现和追溯攻击过程。

**被问到「能不能用 AI」时：** 终端合规按标准判定，不需要 AI。
