## 问题

财务每月把工资表复制粘贴成几十份、逐个发邮件，费时且容易发错人，工资信息一旦发错就是严重的隐私事故。

## 适用场景

- 适合：员工几十人以上、每月手工发工资条的公司
- 不值得：HR 系统已经提供电子工资条的
- 前提：有员工个人邮箱或企业微信，有身份证号等验证信息

## 工具选型

| 方案                      | 特点              | 适用        |
| ------------------------- | ----------------- | ----------- |
| Python + PDF 加密 + SMTP  | 零成本            | ✅ 方案采用 |
| 企业微信 / 钉钉工资条功能 | 员工在 App 里查看 | 国内常用    |
| HR 薪资系统自带           | 和算薪一体        | 中大型企业  |
| Excel 邮件合并            | 不写代码          | 但无法加密  |

企业微信、钉钉自带工资条最省事；需要发到个人邮箱、加密 PDF 时用脚本。

## 怎么做

- 工资表放进只有财务能访问的目录，脚本读取每一行，按模板生成个人工资条 PDF
- PDF 用员工身份证后六位加密，即使误发别人也打不开
- 先给财务发送一份试发预览（前 3 人），确认无误后再全量发送；收件地址取自通讯录，不从工资表里读，防止表格里的地址被改
- 发送完成后生成回执表：成功、失败、退信，失败的单独补发

## 实施步骤

| 步骤 | 做什么                   | 怎么验证               |
| ---- | ------------------------ | ---------------------- |
| 1    | 设计工资条模板           | HR 确认格式            |
| 2    | 读取工资表，逐行生成 PDF | 每人一份               |
| 3    | 用身份证后六位加密       | 不输入密码打不开       |
| 4    | 先发 3 人预览给财务确认  | 财务确认无误           |
| 5    | 全量发送并生成回执       | 有成功、失败、退信清单 |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
from pypdf import PdfReader, PdfWriter

for row in sheet.iter_rows(min_row=2, values_only=True):
    emp = Employee(*row)
    pdf = render_payslip(emp)               # 按模板生成 PDF
    w = PdfWriter(clone_from=PdfReader(pdf))
    w.encrypt(user_password=emp.id_card[-6:])
    send_mail(directory[emp.no], f"{month} 工资条", attachment=w)
```

## 常见坑

- **工资表里的邮箱被改**：表格被篡改导致发给别人。收件地址从通讯录读取，不从工资表读。
- **邮件被识别为垃圾邮件**：短时间大量发送。控制发送速率，使用公司邮件服务器。
- **员工忘了密码规则**：打不开 PDF。邮件正文说明密码规则，不写密码本身。

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会让财务把工资表放进只有财务能访问的目录，脚本逐行生成个人工资条 PDF，用身份证后六位加密，即使误发别人也打不开。先给财务发前 3 人的预览确认，再全量发送；收件地址取自通讯录而不是工资表，防止表格被改。发送完成生成回执表，失败的单独补发。

常见追问：

**问：为什么收件地址不从工资表读？**

答：工资表可能被改错或篡改，通讯录是受控的数据源，避免把工资发给错误的人。

**问：工资数据的安全要注意什么？**

答：最小访问范围、加密传输和存储、发送前预览、操作留痕。

**问：PDF 加密安全吗？**

答：能防止误发后被直接查看；身份证后六位强度一般，更高要求用员工自己设置的密码或在 App 内查看。

**被问到「能不能用 AI」时：** 工资数据敏感且必须准确，不经过 AI。
