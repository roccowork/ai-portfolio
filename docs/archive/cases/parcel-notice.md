## 问题

快递堆在前台，前台在群里喊名字，员工经常没看到；贵重快递丢了说不清谁拿走了。

## 适用场景

- 适合：员工上百人、快递量大的办公室
- 不值得：快递很少的
- 前提：员工在企业通讯录里，前台有手机

## 工具选型

| 方案                  | 特点           | 适用        |
| --------------------- | -------------- | ----------- |
| 智能快递柜            | 自动通知取件码 | 办公楼常用  |
| 企业微信小程序 + 脚本 | 自建           | ✅ 方案采用 |
| 行政 SaaS 前台模块    | 访客 + 快递    | 国内        |
| 群里喊名字            | 现状           | 容易漏      |

有快递柜最简单；没有的用手机扫码登记 + 企业微信通知，成本很低。

## 怎么做

- 前台用手机扫描快递单号并拍照，输入收件人姓名或手机号后四位
- 系统在通讯录里匹配员工，发企业微信通知，附照片和存放位置
- 取件时员工扫码确认，记录取件时间
- 超过 3 天未取再提醒；寄件也可以登记，自动生成寄件记录

## 实施步骤

| 步骤 | 做什么                      | 怎么验证           |
| ---- | --------------------------- | ------------------ |
| 1    | 前台登记页面（扫码 + 拍照） | 几秒完成一件登记   |
| 2    | 按姓名或手机号匹配员工      | 重名时提示人工选择 |
| 3    | 发送带照片的通知            | 员工收到通知       |
| 4    | 取件扫码确认                | 有取件记录         |
| 5    | 未取提醒                    | 3 天后再提醒       |

## 常见坑

- **重名导致通知错人**：只按姓名匹配。加手机号后四位；不能唯一匹配时人工选择。
- **快递照片包含个人信息**：面单上有地址和电话。只私信收件人，不发群。
- **寄件费用归属不清**：没有记录。寄件登记部门和用途。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：识别面单照片上的收件人信息
- **不该交给 AI**：匹配员工时不能唯一确定的交给人
- **怎么落地**：OCR 识别面单，匹配规则 + 人工兜底

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会让前台用手机扫描快递单号并拍照，输入收件人姓名或手机号后四位，系统在通讯录里匹配员工并发带照片和存放位置的企业微信通知；员工取件时扫码确认，3 天未取再提醒；不能唯一匹配时交给前台人工选择。

常见追问：

**问：为什么用手机号后四位辅助匹配？**

答：解决重名问题，又不用前台输入完整手机号。

**问：这种小自动化值得做吗？**

答：开发成本低、每天都在用、员工感受明显，是推广自动化的好例子。

**问：面单信息怎么保护？**

答：照片只发给收件人本人，定期删除登记照片。

**被问到「能不能用 AI」时：** AI 识别面单，省去前台手工输入。
