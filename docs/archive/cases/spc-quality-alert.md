## 问题

质检只判断合格不合格，等出现不合格品时已经生产了一批废品；尺寸慢慢漂移的趋势没人注意。

## 适用场景

- 适合：批量生产、有关键尺寸或参数需要控制的制造企业
- 不值得：单件定制、无法统计的生产
- 前提：关键特性有测量数据，测量系统可靠

## 工具选型

| 方案                  | 特点             | 适用        |
| --------------------- | ---------------- | ----------- |
| Minitab               | 统计分析经典工具 | 国内外都用  |
| MES / QMS 的 SPC 模块 | 和质量系统一体   | 中大型工厂  |
| Python 自写判异       | 实时告警         | ✅ 方案采用 |
| Excel 控制图          | 手工             | 事后分析    |

Minitab 适合分析，实时告警需要接数据流；用 Python 实现常用判异规则即可。

## 怎么做

- 关键尺寸的测量数据（测量设备导出或手机录入）实时进入系统
- 用历史稳定数据计算控制线（均值 ± 3 倍标准差），比规格线更严
- 按判异规则检查：超出控制线、连续 7 点在均值同一侧、连续 6 点上升或下降
- 触发时通知质量工程师和设备操作员，在出现不良品前调整

## 实施步骤

| 步骤 | 做什么                   | 怎么验证               |
| ---- | ------------------------ | ---------------------- |
| 1    | 确定关键特性和测量方式   | 质量部门确认           |
| 2    | 收集稳定期数据计算控制线 | 控制线合理             |
| 3    | 实现判异规则             | 历史数据回放能识别异常 |
| 4    | 实时告警                 | 模拟偏移时收到告警     |
| 5    | 记录处理措施             | 形成闭环               |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
mean, sigma = baseline.mean(), baseline.std()
ucl, lcl = mean + 3 * sigma, mean - 3 * sigma
last = values[-7:]
if values[-1] > ucl or values[-1] < lcl:
    alert("超出控制线")
elif len(last) == 7 and (all(v > mean for v in last) or all(v < mean for v in last)):
    alert("连续 7 点在均值同一侧，过程可能偏移")
```

## 常见坑

- **用规格线当控制线**：规格线是客户要求，控制线是过程能力。控制线由过程数据计算。
- **测量系统本身误差大**：量具不准。先做测量系统分析（MSA）。
- **控制线一直不更新**：工艺改进后过程变了。工艺变更后重新计算。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：用视觉模型做外观缺陷检测，补充尺寸测量
- **不该交给 AI**：判异规则确定
- **怎么落地**：视觉检测作为补充数据源

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会把关键尺寸的测量数据实时接进来，用稳定期的数据算控制线（均值加减 3 倍标准差），按判异规则检查：超出控制线、连续 7 点在均值同一侧、连续 6 点上升或下降，触发时通知质量工程师和操作员，在出现不良品之前调整设备。

常见追问：

**问：控制线和规格线的区别？**

答：规格线是客户或设计要求的合格范围；控制线由过程数据算出，反映过程本身的波动，更早发现异常。

**问：什么是 Cpk？**

答：过程能力指数，衡量过程在规格范围内稳定生产的能力，一般要求大于 1.33。

**问：为什么连续 7 点同侧也算异常？**

答：随机情况下连续 7 点在同一侧的概率很小，说明过程均值可能已经偏移。

**被问到「能不能用 AI」时：** SPC 判异是统计规则，AI 视觉检测可以补充外观缺陷。
