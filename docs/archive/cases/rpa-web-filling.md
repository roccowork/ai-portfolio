## 问题

很多系统没有接口，只能在网页上一条条填：每天把订单录入供应商门户、每月在申报网站填数据，枯燥又容易填错。

## 适用场景

- 适合：需要往没有接口的网页系统重复录入数据的岗位
- 不值得：系统有 API 的（优先用 API）
- 前提：有权限操作该系统，页面结构相对稳定

## 工具选型

| 方案                            | 特点             | 适用        |
| ------------------------------- | ---------------- | ----------- |
| Playwright（Python）            | 稳定，代码可测试 | ✅ 方案采用 |
| 影刀 RPA                        | 国产，录制操作   | 国内常用    |
| UiPath / Power Automate Desktop | 企业级 RPA       | 外企常用    |
| Selenium                        | 老牌浏览器自动化 | 存量多      |

Playwright 自动等待元素、定位方式稳定；业务人员自己维护时可以选影刀这类录制工具。

## 怎么做

- 用 Playwright 控制浏览器：登录 → 打开录入页面 → 按 Excel 每行填写表单 → 提交 → 截图
- 用页面元素的标签文字定位输入框，比坐标点击稳定；每步等待页面加载完成
- 每条结果（成功、失败原因、截图路径）写回 Excel；遇到验证码或页面改版就停下来通知人
- 只用于本单位有权限操作的系统，遵守网站的使用条款

## 实施步骤

| 步骤 | 做什么                      | 怎么验证         |
| ---- | --------------------------- | ---------------- |
| 1    | 梳理录入流程和字段对应      | 有一份字段映射表 |
| 2    | Playwright 登录并打开录入页 | 能自动登录       |
| 3    | 按 Excel 逐行填写提交       | 测试数据提交成功 |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
for row in rows:
    page.goto(f"{BASE}/order/new")
    page.get_by_label("客户名称").fill(row["客户"])
    page.get_by_label("数量").fill(str(row["数量"]))
    page.get_by_role("button", name="提交").click()
    page.wait_for_selector("text=提交成功", timeout=10_000)
    page.screenshot(path=f"proof/{row['单号']}.png")
```

## 常见坑

- **元素定位不稳定**：用坐标或复杂的 CSS 路径。用 get_by_label、get_by_role 按文字定位。
- **页面加载慢导致失败**：没有等待。等待特定元素或成功提示出现。
- **账号被锁定**：频繁登录。复用登录状态，控制速度。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：页面改版时 AI 自动识别输入框，减少脚本维护
- **不该交给 AI**：提交的数据必须来自表格，不能让 AI 生成
- **怎么落地**：AI 做元素定位兜底，数据仍来自表格

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 对没有接口的网页系统，我会用 Playwright 控制浏览器：登录、打开录入页、按 Excel 每行填写表单、提交、截图，每条结果写回 Excel。用标签文字和角色定位输入框，比坐标点击稳定；遇到验证码或页面改版就停下来通知人。只用于本单位有权限操作的系统，遵守使用条款。

常见追问：

**问：RPA 和 API 集成怎么选？**

答：有 API 优先用 API，稳定、快、不受页面改版影响；没有 API 时才用 RPA。

**问：RPA 最大的问题是什么？**

答：页面一改就可能失效，维护成本高；要有失败告警和留证。

**问：Playwright 和 Selenium 的区别？**

答：Playwright 自带自动等待、更快、多浏览器支持好；Selenium 历史长、生态大。

**被问到「能不能用 AI」时：** AI 能在页面改版时自动找到输入框，数据仍严格来自表格。
