## 问题

中小企业没有专职 IT，服务器有没有备份、补丁多久没打、离职员工账号停没停，没人说得清。人工检查每台机器要大半天，写报告又要半天。

## 适用场景

- 适合：没有专职 IT 的中小企业（10～200 人），或者 IT 服务商给新客户做第一次评估
- 不值得：已经有完善监控和资产系统的大公司
- 前提：客户授权，能在每台服务器上用管理员身份运行只读脚本

## 工具选型

| 方案                         | 特点                     | 适用                     |
| ---------------------------- | ------------------------ | ------------------------ |
| 自写采集 + 规则（本站）      | 只读、离线、报告面向老板 | ✅ 本站实现              |
| Microsoft 安全基线 / CIS-CAT | 标准的合规检查           | 偏技术，报告不适合老板看 |
| Lynis                        | Linux 基线检查           | 只覆盖 Linux             |
| 商业 RMM（如 NinjaOne）      | 持续监控和管理           | 需要装客户端、按设备收费 |

自写：上门半天就能完成，不需要装任何软件，报告用老板听得懂的话写，按风险和时限排序。

## 怎么做

- **采集只读**：不改任何配置、不联网、不读业务数据和密码；运行前可以把脚本给客户的人看
- Windows 采集兼容 PowerShell 5.1（Server 2012 R2 起）；Linux 采集不依赖 jq 和 Python
- **规则引擎**按风险分级：高（1 周内处理）、中（1 个月内）、低（择机）。同一级别里备份排第一，因为数据丢了找不回来
- 报告面向老板：标题写「出了什么问题」，说明写「具体情况」，建议写「怎么改」，不堆术语
- 报告生成器只用 Python 标准库，带一台装了 Python 的笔记本就能用

## 常见坑

- **Windows 脚本必须是 UTF-8 带 BOM**：中文 Windows 上的 PowerShell 5.1 读取不带 BOM 的文件时按 GBK 解析，中文会乱码甚至报语法错误。CI 里加了检查。

## AI 视角

**✨ AI 能增强**

## 面试怎么讲

30 秒讲法：

> 我做了一套给中小企业用的 IT 体检工具：只读采集脚本覆盖 Windows 和 Linux，带回 JSON 后规则引擎按高中低分级，生成给老板看的报告，标题写出了什么问题、建议写怎么改和多久内处理。同一级别里备份排第一，因为数据丢了找不回来。采集完全只读、不联网，可以先给客户的人看脚本。示例报告用的是虚构数据。

常见追问：

**问：为什么卷影副本不算备份？**

答：卷影副本和数据在同一块盘上，盘坏了、被勒索加密时一起丢；备份必须在另一个介质或位置。

**问：Windows 脚本为什么要 UTF-8 带 BOM？**

答：中文 Windows 的 PowerShell 5.1 读取不带 BOM 的文件按 GBK 解析，中文会乱码甚至语法错误。

**问：报告怎么写老板才看得懂？**

答：先说结论和评分，再列需要优先处理的问题；每条写现象、风险、怎么改、多久内改，不堆术语。

**被问到「能不能用 AI」时：** 风险判定用规则，AI 帮把报告写得老板更容易看懂。
