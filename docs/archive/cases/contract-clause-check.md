## 问题

法务每份合同都要从头读，重点检查付款、违约、责任上限、知识产权、管辖等条款；合同多时排队好几天，业务等不及。

## 适用场景

- 适合：合同量大、法务人手少的公司
- 不值得：合同很少、都用自己模板的
- 前提：有书面的合同审查清单，合同内容可以交给模型处理（或私有部署）

## 工具选型

| 方案                                 | 特点         | 适用        |
| ------------------------------------ | ------------ | ----------- |
| 法律科技产品（幂律、法大大智能审查） | 国产合同审查 | 国内常用    |
| Kira / Luminance                     | 外企合同分析 | 外企常用    |
| 规则 + 大模型自建                    | 按公司清单   | ✅ 方案采用 |
| 人工通读                             | 现状         | 慢          |

规则处理确定性检查，大模型处理需要理解的条款，并要求引用原文便于法务核对。

## 怎么做

- 把公司的合同审查清单整理成规则：必须有的条款、不能接受的条件（无限责任、单方解除）、需要关注的数字（付款期限、违约金比例）
- 规则能判断的用规则（关键词、金额、期限），需要理解的条款用大模型按清单逐条判断并给出原文依据
- 生成审查意见：每条标出风险等级、原文位置和建议修改
- 最终意见由法务确认，系统只是帮法务先过一遍

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
CHECKLIST = ["付款期限是否超过 60 天", "是否有责任上限条款", "违约金是否超过合同金额 20%",
             "知识产权归属是否明确", "争议解决地是否为我方所在地"]
for item in CHECKLIST:
    r = llm.extract(text=contract_text, schema={"result": ["符合", "不符合", "未提及"], "quote": "str"},
                    instructions=f"检查：{item}。必须引用合同原文作为依据。")
    findings.append((item, r))
```

## 常见坑

- **模型误判或编造**：没有要求引用原文。每条结论必须引用原文，法务核对。
- **合同泄露**：发给外部模型。评估保密要求，敏感合同用私有部署或不使用。
- **清单不更新**：法规和公司政策变化。法务定期维护清单。

## AI 视角

**🤖 AI 是核心**

- **AI 能做什么**：按审查清单逐条判断并引用原文
- **不该交给 AI**：最终法律意见必须由法务给出
- **怎么落地**：见正文

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会把公司的合同审查清单整理成规则：付款期限、责任上限、违约金比例、知识产权归属、争议解决地等。能用关键词和数字判断的用规则，需要理解的条款让大模型按清单逐条判断并必须引用原文，生成带风险等级和修改建议的初审意见，最终由法务确认。

常见追问：

**问：AI 审合同能代替法务吗？**

答：不能。它帮法务先过一遍、标出问题，最终判断和责任在法务。

**问：为什么必须引用原文？**

答：方便核对，也能发现模型编造。

**问：合同审查重点看哪些条款？**

答：主体、标的、价款和付款、交付验收、违约责任、责任限制、知识产权、保密、争议解决。

**被问到「能不能用 AI」时：** 这个案例本身就是 AI，关键是引用原文、法务最终确认。
