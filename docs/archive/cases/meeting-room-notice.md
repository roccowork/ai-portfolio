## 问题

会议上定了很多事，会后没人跟进；纪要发在群里很快被刷掉，到下次开会才发现没人做。

## 适用场景

- 适合：会议多、会后事项跟进差的团队
- 不值得：会议很少的
- 前提：团队愿意用统一的纪要模板

## 工具选型

| 方案                      | 特点           | 适用        |
| ------------------------- | -------------- | ----------- |
| 飞书/企业微信文档 + n8n   | 按固定格式解析 | ✅ 方案采用 |
| 飞书妙记、腾讯会议纪要    | 自动转写和总结 | 国内常用    |
| Microsoft Teams + Planner | 会议和任务一体 | 外企常用    |
| Notion / Jira             | 任务管理       | 外企        |

用固定格式写待办，正则就能可靠解析，不依赖 AI，没有额外费用。

## 怎么做

- 统一纪要模板：待办写成「- [ ] 事项 @负责人 截止日期」
- 会议日程结束后，n8n 读取纪要文档，用正则拆出每条待办，在任务系统里创建任务并私信负责人
- 截止前一天提醒，逾期在下次会议的议程里自动列出来
- 不需要 AI：靠固定格式就能解析，可靠而且没有额外费用

## 效果指标

| 指标     | 做之前         | 预期效果（估算）   |
| -------- | -------------- | ------------------ |
| 会后跟进 | 靠记忆         | 每条待办有人有日期 |
| 逾期发现 | 下次开会才发现 | 截止前提醒         |
| 纪要分发 | 发群里被刷掉   | 直接私信负责人     |

会议决定落到具体的人和日期上，跟进不再靠记忆。

## 常见坑

- **格式不规范解析不到**：有人不按模板写。解析失败时提醒会议组织者。
- **负责人名字对不上账号**：@ 的是昵称。用 IM 的 @ 提及功能，拿到用户 ID。
- **任务太多没人看**：把讨论内容也当待办。只提取明确的「待办」行。

## AI 视角

**🤖 AI 是核心**

- **AI 能做什么**：从会议录音或纪要里提取待办、负责人和截止日期
- **不该交给 AI**：待办需要负责人确认
- **怎么落地**：会议转写 + AI 提取待办，负责人确认

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会统一纪要模板，待办写成「- [ ] 事项 @负责人 截止日期」。会议结束后 n8n 读取纪要，用正则拆出每条待办，在任务系统里创建任务并私信负责人，截止前一天提醒，逾期的在下次会议议程里自动列出。靠固定格式解析，不依赖 AI，可靠而且没有额外费用。

常见追问：

**问：为什么不用 AI 总结会议？**

答：AI 总结适合生成摘要，但待办的负责人和日期必须准确；固定格式更可靠，也可以两者结合。

**问：自动化推不动怎么办？**

答：先在一个团队试点，证明效果后推广；工具要尽量不增加额外操作。

**问：任务跟进的关键是什么？**

答：每项有明确的负责人和截止日期，到期有提醒，逾期有人看见。

**被问到「能不能用 AI」时：** 以前要靠固定格式，AI 能直接从会议记录里提取待办。
