## 问题

客服 70% 的时间在回答重复问题：几点下班、怎么开发票、退货地址是什么；高峰期客户排队，真正复杂的问题反而没人及时处理。

## 适用场景

- 适合：重复问题多、客服人力紧张的业务
- 不值得：咨询量很小、问题都很个性化的
- 前提：能整理出常见问题和标准答案

## 工具选型

| 方案                         | 特点                   | 适用               |
| ---------------------------- | ---------------------- | ------------------ |
| 企业微信客服 + 关键词/相似度 | 零成本                 | ✅ 方案采用        |
| 智齿、网易七鱼               | 国产客服系统，含机器人 | 国内常用           |
| Zendesk / Intercom           | 外企客服平台           | 外企常用           |
| 大模型 + 知识库检索（RAG）   | 语义理解强             | 成本和准确性要控制 |

先用关键词和相似度覆盖高频问题，成本为零、可控；命中率不够再考虑大模型。

## 怎么做

- 整理高频问题和标准答案成知识库，每个问题配几种常见问法
- 先用关键词和文本相似度匹配，命中且置信度高就自动回复；不确定时给出 2～3 个候选问题让客户选
- 匹配不到或客户说「人工」就转人工客服，并把之前的对话一起带过去
- 每周统计没匹配上的问题，补充到知识库，命中率逐步提高

## 实施步骤

| 步骤 | 做什么                       | 怎么验证                 |
| ---- | ---------------------------- | ------------------------ |
| 1    | 整理高频问题和标准答案       | 覆盖八成咨询             |
| 2    | 每个问题配多种问法           | 测试问法都能命中         |
| 3    | 接入客服通道，设置置信度阈值 | 低置信度时给候选或转人工 |
| 4    | 转人工时带上对话记录         | 客服能看到上下文         |
| 5    | 每周补充未命中问题           | 命中率逐周提高           |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
from difflib import SequenceMatcher

def answer(q):
    best = max(faq, key=lambda f: max(SequenceMatcher(None, q, s).ratio() for s in f.questions))
    score = max(SequenceMatcher(None, q, s).ratio() for s in best.questions)
    return best.answer if score > 0.6 else None   # None 转人工
```

## 效果指标

| 指标     | 做之前         | 预期效果（估算） |
| -------- | -------------- | ---------------- |
| 重复问题 | 客服逐个回答   | 自动回复         |
| 客户等待 | 高峰期排队     | 常见问题秒回     |
| 客服精力 | 被重复问题占满 | 专注复杂问题     |

重复问题自动解决，客服专注处理复杂问题。也可以接入大模型做语义理解，但要控制成本和回答范围。

## 常见坑

- **答非所问**：阈值太低。提高阈值，不确定时给候选问题。
- **知识库过时**：政策变了没更新。知识库有负责人，变更时同步更新。
- **客户被困在机器人里**：找不到人工入口。任何时候说「人工」都能转人工。

## AI 视角

**🤖 AI 是核心**

- **AI 能做什么**：理解客户的各种说法，基于知识库回答
- **不该交给 AI**：退款、赔偿等承诺必须转人工
- **怎么落地**：接大模型 + 知识库检索，敏感问题转人工

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会把高频问题和标准答案整理成知识库，每个问题配几种常见问法。客户提问时先用关键词和文本相似度匹配，置信度高就自动回复，不确定时给出两三个候选问题；匹配不到或客户说「人工」就转人工，并带上之前的对话。每周统计没匹配上的问题补充到知识库。

常见追问：

**问：什么是 RAG？**

答：检索增强生成：先从知识库检索相关内容，再让大模型基于检索结果回答，减少编造。

**问：怎么评估客服机器人的效果？**

答：命中率、自动解决率、转人工率、客户满意度。

**问：用大模型做客服要注意什么？**

答：限定回答范围、基于知识库回答、敏感问题转人工、控制成本、记录对话便于审查。

**被问到「能不能用 AI」时：** 客服机器人加上大模型后命中率大幅提高，但涉及赔偿承诺必须转人工。
