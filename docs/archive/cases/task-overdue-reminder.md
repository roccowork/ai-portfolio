## 问题

任务分出去后没人跟进，到期了负责人自己都忘了；项目经理要一个个问进度。

## 适用场景

- 适合：用任务系统分配工作的团队
- 不值得：任务很少、站会就能同步的小团队
- 前提：任务有负责人和截止日期

## 工具选型

| 方案                                           | 特点               | 适用        |
| ---------------------------------------------- | ------------------ | ----------- |
| 任务系统自带提醒（Jira、飞书项目、Teambition） | 开箱即用           | 国内外都有  |
| Python + 企业微信                              | 合并提醒、升级规则 | ✅ 方案采用 |
| n8n 定时流程                                   | 拖拽               | 可选        |
| 人工追问                                       | 现状               | 耗时        |

系统自带的提醒往往一条任务一条消息；自写可以合并、分级和升级。

## 怎么做

- 每天早上读取所有未完成且有截止日期的任务
- 明天到期的提醒负责人；已逾期的每天提醒一次，附逾期天数
- 逾期超过 3 天的汇总给项目经理，按项目和负责人分组
- 同一个人的多条提醒合并成一条消息，避免刷屏

## 实施步骤

| 步骤 | 做什么                       | 怎么验证         |
| ---- | ---------------------------- | ---------------- |
| 1    | 要求任务都有负责人和截止日期 | 团队约定         |
| 2    | 读取未完成任务               | 数据准确         |
| 3    | 按规则生成提醒并合并         | 每人每天一条     |
| 4    | 逾期汇总给项目经理           | 项目经理收到清单 |
| 5    | 周会讨论逾期项               | 形成闭环         |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
by_user = defaultdict(list)
for t in tasks.open_with_due():
    days = (today - t.due).days
    if days == -1 or days > 0:
        by_user[t.assignee].append(f"{'明天到期' if days == -1 else f'已逾期 {days} 天'}：{t.title}")
for user, lines in by_user.items():
    notify(user, "你的任务提醒：\n" + "\n".join(lines))
```

## 效果指标

| 指标         | 做之前 | 预期效果（估算） |
| ------------ | ------ | ---------------- |
| 任务无声逾期 | 常见   | 每天提醒         |
| 项目经理追问 | 逐个问 | 看清单           |
| 提醒打扰     | —      | 合并成每天一条   |

任务不再无声逾期，项目经理不用逐个追问。

## 常见坑

- **提醒太多被屏蔽**：每个任务一条消息。每人每天合并一条。
- **截止日期定得不合理**：经常逾期。复盘逾期原因，调整估算。
- **任务已完成但没更新状态**：被误提醒。提醒里提供一键完成。

## AI 视角

**⚙️ 规则就够**

- **AI 能做什么**：基本不需要
- **不该交给 AI**：逾期判断确定
- **怎么落地**：保持规则

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会每天早上读取任务系统里所有未完成、有截止日期的任务：明天到期的提醒负责人，已逾期的每天提醒并附逾期天数，同一个人的提醒合并成一条；逾期超过 3 天的按项目汇总给项目经理，周会讨论。

常见追问：

**问：为什么要合并提醒？**

答：一条任务一条消息很快被当成噪音屏蔽，合并后更容易被阅读。

**问：任务经常逾期说明什么？**

答：估算偏乐观、需求变化、依赖阻塞或人手不足，需要复盘原因而不只是催。

**问：提醒和升级的区别？**

答：提醒给负责人自己处理；升级给管理者介入协调。

**被问到「能不能用 AI」时：** 逾期提醒用规则就够。
