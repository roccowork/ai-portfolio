## 问题

销售手上商机多，跟着跟着就忘了，客户被竞争对手抢走；主管不知道哪些商机已经停滞。

## 适用场景

- 适合：B2B 销售周期长、商机多的团队
- 不值得：快消零售、没有商机管理的
- 前提：销售在 CRM 里记录跟进

## 工具选型

| 方案             | 特点         | 适用            |
| ---------------- | ------------ | --------------- |
| CRM 自带提醒规则 | 零开发       | 国内外 CRM 都有 |
| CRM API + 脚本   | 按自己的规则 | ✅ 方案采用     |
| n8n 定时流程     | 拖拽         | 可选            |
| Excel 跟进表     | 现状         | 容易遗漏        |

CRM 自带规则能满足的直接用；需要按阶段、升级、周报时用脚本。

## 怎么做

- 按商机阶段设置跟进间隔：初步接触 7 天、方案报价 3 天、谈判 2 天
- 每天读取 CRM 商机和最后跟进时间，超期的私信销售，列出客户名、金额、上次跟进内容
- 超期两倍时间仍未跟进的升级给主管
- 每周给主管一份停滞商机清单，按金额排序

## 实施步骤

| 步骤 | 做什么                       | 怎么验证     |
| ---- | ---------------------------- | ------------ |
| 1    | 和销售主管确定各阶段跟进间隔 | 规则确认     |
| 2    | 读取商机和最后跟进时间       | 数据准确     |
| 3    | 超期提醒销售                 | 销售收到提醒 |
| 4    | 超期两倍升级主管             | 主管收到提醒 |
| 5    | 每周停滞清单                 | 主管周会使用 |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
LIMIT = {"初步接触": 7, "方案报价": 3, "商务谈判": 2}
for opp in crm.open_opportunities():
    idle = (today - opp.last_activity).days
    limit = LIMIT.get(opp.stage, 7)
    if idle > limit * 2:
        notify(opp.owner_manager, f"{opp.customer} 商机已 {idle} 天未跟进（{opp.amount} 元）")
    elif idle > limit:
        notify(opp.owner, f"该跟进 {opp.customer} 了：上次 {opp.last_note}")
```

## 效果指标

| 指标             | 做之前 | 预期效果（估算） |
| ---------------- | ------ | ---------------- |
| 商机遗忘         | 经常   | 自动提醒         |
| 主管掌握停滞商机 | 不清楚 | 每周清单         |
| 跟进记录完整性   | 差     | 提醒促使补记录   |

商机不再因为遗忘而流失，主管随时知道哪些商机停滞了。

## 常见坑

- **销售跟进了没记录**：只在微信里聊。要求跟进记录写入 CRM，否则仍会被提醒。
- **提醒太多被忽略**：间隔设得太短。按阶段设合理间隔，合并成每日一条。
- **已丢单的商机还在提醒**：没有及时关闭。提醒里加「关闭商机」快捷操作。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：根据商机历史生成跟进话术和下一步建议
- **不该交给 AI**：提醒规则确定
- **怎么落地**：提醒里附 AI 生成的跟进建议

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会按商机阶段设跟进间隔，比如方案报价阶段 3 天、谈判阶段 2 天；每天读取 CRM 里商机的最后跟进时间，超期的私信销售并附上次跟进内容，超期两倍升级给主管，每周给主管一份按金额排序的停滞商机清单。

常见追问：

**问：销售漏斗是什么？**

答：商机从线索到成交按阶段划分，每个阶段的数量和转化率，用来预测业绩和发现瓶颈。

**问：为什么不同阶段间隔不同？**

答：越接近成交越需要频繁跟进，否则容易被竞争对手抢走。

**问：怎么让销售愿意记录跟进？**

答：记录简单（语音、快捷模板）、和提醒联动、主管只看 CRM 数据。

**被问到「能不能用 AI」时：** 提醒是规则，AI 根据跟进记录给销售下一步建议。
