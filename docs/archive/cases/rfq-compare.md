## 问题

采购要给几家供应商分别发邮件询价，报价格式各不相同，再手工整理成比价表；审计时还要证明「货比三家」。

## 适用场景

- 适合：采购频繁、要求多家比价的公司（尤其国企、上市公司）
- 不值得：采购很少、固定供应商的
- 前提：有合格供应商名单

## 工具选型

| 方案                     | 特点           | 适用        |
| ------------------------ | -------------- | ----------- |
| SRM 系统（如用友、甄云） | 供应商管理一体 | 国内常用    |
| SAP Ariba / Coupa        | 全球采购平台   | 外企常用    |
| 表单 + 脚本              | 轻量           | ✅ 方案采用 |
| 邮件 + Excel             | 现状           | 耗时        |

采购量大用 SRM；中小公司用统一表单收集报价 + 自动比价，就能满足大部分需求。

## 怎么做

- 采购需求填好物料、数量、交期后，系统给合格供应商发统一格式的询价表单链接
- 截止时间到后自动汇总报价：单价、总价、交期、付款条件、质保
- 按总成本排序，标出最低价和最快交期，异常低价单独提示
- 比价表附在采购审批里，作为「货比三家」的审计证据

## 实施步骤

| 步骤 | 做什么               | 怎么验证       |
| ---- | -------------------- | -------------- |
| 1    | 统一询价表单格式     | 字段确认       |
| 2    | 维护合格供应商名单   | 名单可选       |
| 3    | 发询价并设截止时间   | 供应商收到链接 |
| 4    | 截止后自动生成比价表 | 排名和提示正确 |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
df = pd.DataFrame(quotes)   # 供应商、单价、交期天数、账期天数
df["总价"] = df["单价"] * need.qty
df["排名"] = df["总价"].rank(method="min").astype(int)
df.loc[df["总价"] < df["总价"].median() * 0.6, "提示"] = "报价明显偏低，请核实"
df.sort_values("总价").to_excel(f"比价表-{need.id}.xlsx", index=False)
```

## 常见坑

- **只比单价忽略总成本**：运费、账期、质保不同。比较总拥有成本，列出所有条件。
- **供应商之间串通**：报价接近。关注报价异常一致，定期引入新供应商。
- **报价泄露给其他供应商**：比价表共享范围太大。截止前报价不可见，比价表只给相关人员。

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会把采购需求通过统一格式的表单发给合格供应商，截止后自动汇总单价、总价、交期、付款条件和质保，按总成本排序、标出最优，明显偏低的报价单独提示核实；比价表附在采购审批里，作为「货比三家」的审计证据。

常见追问：

**问：什么是总拥有成本？**

答：不只是采购价，还包括运输、安装、维护、账期等全部成本。

**问：为什么要标出异常低价？**

答：可能是报错、质量问题或恶意低价竞争，需要核实。

**问：询价、招标、竞价的区别？**

答：询价适合金额较小、标准化的采购；招标适合金额大、需要公开公平；竞价是在线多轮报价。

**被问到「能不能用 AI」时：** AI 能解析供应商各种格式的报价单，排序仍用规则。
