## 问题

访客 Wi-Fi 密码贴在墙上几年不换，离职员工、楼下邻居都能连；访客和办公电脑在同一个网络，存在安全风险。

## 适用场景

- 适合：有访客接待、对办公网安全有要求的公司
- 不值得：只有几个人、没有访客的小办公室
- 前提：无线控制器或 AP 支持 RADIUS 认证或 API 创建账号

## 工具选型

| 方案                                     | 特点               | 适用        |
| ---------------------------------------- | ------------------ | ----------- |
| FreeRADIUS + 自写登记页                  | 开源，灵活         | ✅ 方案采用 |
| 无线厂商的访客门户（华为、Aruba、UniFi） | 自带访客账号管理   | 最常用      |
| 短信 / 微信认证门户                      | 国内公共场所常用   | 国内        |
| PSK 每日更换                             | 简单但所有访客共用 | 小办公室    |

优先用无线厂商自带的访客功能；需要和登记、被访人通知打通时，自写登记页 + RADIUS。

## 怎么做

- 访客网络单独一个 VLAN，只能访问互联网，不能访问公司内网（交换机 ACL / 防火墙策略）
- 访客扫码填写姓名、手机号、被访人，系统生成当天 23:59 过期的账号，写入 RADIUS
- 密码通过短信或登记完成页面展示；被访人收到企业微信通知
- 登记记录保留，满足来访登记和网络安全审计要求

## 实施步骤

| 步骤 | 做什么                        | 怎么验证               |
| ---- | ----------------------------- | ---------------------- |
| 1    | 划分访客 VLAN，只能访问互联网 | 访客网络 ping 不通内网 |
| 2    | 部署登记页和 RADIUS           | 登记后能连上 Wi-Fi     |
| 3    | 账号当天 23:59 失效           | 第二天无法使用         |
| 4    | 通知被访人                    | 被访人收到企业微信消息 |
| 5    | 登记记录保留                  | 能查到某天的访客       |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
user = f"guest{secrets.randbelow(10**6):06d}"
pwd = secrets.token_urlsafe(6)
expire = datetime.combine(date.today(), time(23, 59))
radius.add_user(user, pwd, expiration=expire, vlan=GUEST_VLAN)
notify_host(host_name, f"{guest_name} 已到访，Wi-Fi 账号已发送")
```

## 效果指标

| 指标           | 做之前           | 预期效果（估算）           |
| -------------- | ---------------- | -------------------------- |
| Wi-Fi 密码泄露 | 贴在墙上几年不换 | 每个访客独立账号、当天失效 |
| 访客访问内网   | 可能             | VLAN 隔离                  |
| 来访登记       | 纸质             | 电子记录                   |

访客上网方便，办公网安全；每个访客都有登记记录。

## 常见坑

- **访客 VLAN 能访问内网**：防火墙规则没配。访客 VLAN 只放行到互联网的流量，拒绝私有网段。
- **登记页被滥用批量注册**：没有限制。手机号验证、同一号码每天限次数。
- **访客流量占满带宽**：下载大文件。访客网络限速。

**⚙️ 规则就够**

- **不该交给 AI**：账号和隔离规则确定

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会把访客网络单独划一个 VLAN，只能访问互联网、不能访问内网。访客扫码登记姓名、手机号和被访人，系统生成当天 23:59 过期的账号写入 RADIUS，密码显示在页面或发短信，被访人收到企业微信通知。登记记录保留，满足来访登记和网络安全审计。

常见追问：

**问：VLAN 隔离是怎么实现的？**

答：访客 SSID 映射到单独的 VLAN，三层网关或防火墙上配置 ACL，只允许访问互联网。

**问：WPA2-PSK 和 WPA2-Enterprise 的区别？**

答：PSK 所有人共用一个密码；Enterprise 通过 RADIUS 每人独立账号，可以单独禁用和审计。

**问：为什么访客上网要登记？**

答：网络安全法要求公共网络能追溯到使用人；也便于出现问题时排查。

**被问到「能不能用 AI」时：** 访客网络用规则就够。
