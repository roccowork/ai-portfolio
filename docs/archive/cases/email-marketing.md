## 问题

市场部群发同一封邮件给所有人，打开率低还被标为垃圾邮件；对资料感兴趣的潜在客户没人跟进，热度很快消失。

## 适用场景

- 适合：B2B 和需要培育线索的业务，外企市场部尤其常用
- 不值得：主要靠线下渠道、客户很少用邮件的
- 前提：有合法获得的邮件订阅名单，用户行为数据可获取

## 工具选型

| 方案                      | 特点           | 适用     |
| ------------------------- | -------------- | -------- |
| HubSpot / Marketo         | 营销自动化平台 | 外企常用 |
| Mautic                    | 开源营销自动化 | 自建     |
| Mailchimp                 | 邮件营销       | 中小企业 |
| 企业微信 / 公众号模板消息 | 国内触达渠道   | 国内常用 |

外企常用 HubSpot；国内更多用企业微信和公众号，但「按行为触发序列」的思路相同。

## 怎么做

- 按行为触发不同序列：新注册用户收到入门指南，下载白皮书的收到相关案例，试用快到期的收到购买优惠
- 邮件按客户行业、名字个性化，统计打开和点击
- 打开、点击多次的高意向线索自动推给销售（和 CRM 同步）
- 退订、退信自动处理；配置 SPF、DKIM、DMARC，提高送达率

## 实施步骤

| 步骤 | 做什么                          | 怎么验证         |
| ---- | ------------------------------- | ---------------- |
| 1    | 配置发信域名的 SPF、DKIM、DMARC | 邮件不进垃圾箱   |
| 2    | 接入用户行为事件                | 注册、下载能触发 |
| 3    | 设计序列和内容                  | 市场部确认       |
| 4    | 统计打开、点击，打分            | 高意向线索被识别 |
| 5    | 同步 CRM 并通知销售             | 销售收到线索     |

## 关键代码

示例代码（简化），没有在生产环境运行：

```yaml
# 线索培育序列示意
trigger: { event: whitepaper_download }
steps:
  - { wait: 0d, send: 感谢下载 + 相关案例 }
  - { wait: 3d, send: 行业解决方案, if: not_unsubscribed }
  - { wait: 7d, send: 预约演示邀请, if: opened_any }
  - { if: 'clicks >= 2', action: assign_to_sales }
```

## 效果指标

| 指标       | 做之前       | 预期效果（估算） |
| ---------- | ------------ | ---------------- |
| 邮件打开率 | 群发很低     | 个性化后提升     |
| 线索跟进   | 热度消失     | 当天交给销售     |
| 市场人工   | 每次手动群发 | 序列自动运行     |

营销从群发变成按行为个性化培育，高意向线索及时交给销售。

## 常见坑

- **邮件进垃圾箱**：发信域名没有认证。配置 SPF、DKIM、DMARC，控制发送速率。
- **违规发送**：没有用户同意。只发给订阅用户，每封都有退订链接。
- **打开率统计不准**：部分客户端预加载图片。结合点击率判断。

## AI 视角

**🤖 AI 是核心**

- **AI 能做什么**：按客户行业和行为生成个性化邮件内容，做主题行 A/B 测试
- **不该交给 AI**：发送对象和退订规则必须确定、合规
- **怎么落地**：AI 生成内容草稿，市场人员审核后进入序列

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会按客户行为触发不同的邮件序列：下载白皮书的第 0、3、7 天分别收到相关案例、行业方案和演示邀请，打开和点击多次的高意向线索自动同步到 CRM 交给销售；退订和退信自动处理，发信域名配置 SPF、DKIM、DMARC 保证送达率。

常见追问：

**问：SPF、DKIM、DMARC 是什么？**

答：SPF 声明哪些服务器可以代表域名发信，DKIM 给邮件签名，DMARC 规定验证失败时的处理方式，三者一起提高送达率、防伪造。

**问：线索评分怎么做？**

答：按行为加分（打开、点击、访问价格页）和属性加分（行业、规模），超过阈值交给销售。

**问：国内邮件营销效果差怎么办？**

答：国内更多用企业微信、公众号、短信触达，思路一样：按行为分层、个性化、追踪转化。

**被问到「能不能用 AI」时：** AI 让每封营销邮件按客户行业个性化，但发送名单和退订必须合规。
