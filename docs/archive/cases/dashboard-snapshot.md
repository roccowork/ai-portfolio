## 问题

辛苦做好的监控看板，除了运维没人看；领导想知道系统情况只能问人。

## 适用场景

- 适合：管理层、业务方不常登录监控系统，但需要每天了解情况的团队
- 不值得：团队都习惯直接看 Grafana 的
- 前提：已有 Grafana 看板

## 工具选型

| 方案                          | 特点                     | 适用                     |
| ----------------------------- | ------------------------ | ------------------------ |
| Grafana Image Renderer        | 官方插件，按面板渲染 PNG | ✅ 方案采用              |
| Grafana 报表（企业版）        | 定时生成 PDF 邮件        | 企业版功能               |
| Playwright 截图               | 整页截图，灵活           | 需要处理登录             |
| BI 工具订阅（帆软、Power BI） | 业务报表                 | 国内帆软 / 外企 Power BI |

选 Image Renderer：开源免费，按面板 ID 精确渲染，配合群机器人就能每天推送。

## 怎么做

- 安装 Grafana Image Renderer 插件，通过 `/render/d-solo/` 接口把指定面板渲染成 PNG
- 选 3～4 个最关键的面板（访问量、错误率、核心业务量），按固定时间范围（昨天全天）渲染
- 企业微信群机器人支持发送图片（base64 + md5），图片下面再发一行关键数字
- 和运维周报配合：日报看趋势图，周报看汇总数字

## 实施步骤

| 步骤 | 做什么                           | 怎么验证                        |
| ---- | -------------------------------- | ------------------------------- |
| 1    | 安装 Grafana Image Renderer      | `/render/d-solo/...` 能返回 PNG |
| 2    | 创建只读服务账号和令牌           | 令牌只有查看权限                |
| 3    | 选 3～4 个关键面板，固定时间范围 | 渲染结果清晰可读                |
| 4    | 脚本渲染并通过群机器人发送图片   | 群里收到图片                    |
| 5    | CronJob 每天 08:30 运行          | 连续几天按时收到                |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
url = f"{GRAFANA}/render/d-solo/{uid}/overview?panelId={pid}&from=now-1d&to=now&width=1000&height=400"
png = requests.get(url, headers={"Authorization": f"Bearer {token}"}, timeout=60).content
requests.post(WEBHOOK, json={"msgtype": "image", "image": {
    "base64": base64.b64encode(png).decode(), "md5": hashlib.md5(png).hexdigest()}})
```

## 常见坑

- **渲染出来是空白或加载中**：数据查询慢，渲染超时。加大渲染超时；面板查询优化；时间范围不要太长。
- **Image Renderer 占内存**：每次渲染启动一个浏览器。作为独立服务部署，限制并发。
- **图片超过群机器人大小限制**：图片太大。控制宽高，企业微信图片限 2MB。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：给每天的图表配一段文字解读：「昨天流量比上周高 20%，主要来自……」
- **不该交给 AI**：图表数据本身要直接来自监控系统
- **怎么落地**：渲染图片后把关键数据交给模型生成两三句解读一起推送

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会安装 Grafana Image Renderer，每天早上 8 点半由定时任务渲染 3～4 个关键面板（访问量、错误率、核心业务量）的 PNG，通过企业微信群机器人发图片，再附一行关键数字。用只读令牌访问 Grafana。这样管理层不用登录就能看到昨天的情况，和每周周报互补。

常见追问：

**问：企业微信群机器人怎么发图片？**

答：msgtype 为 image，内容是图片的 base64 和 md5，大小不超过 2MB。

**问：为什么不直接给管理层 Grafana 账号？**

答：大多数人不会主动登录；推送到常用的群里更容易被看到。

**问：看板设计有什么原则？**

答：少而精：最重要的指标放最上面，每个面板回答一个问题，标注阈值线。

**被问到「能不能用 AI」时：** 图表配一句 AI 解读，管理层不用看懂图也能知道发生了什么。
