## 问题

客户合同到期了才想起续约，客户已经换了供应商；客户早就不怎么用了，没人发现。

## 适用场景

- 适合：订阅制、年度服务合同的公司（SaaS、运维外包、IT 服务）
- 不值得：一次性买卖
- 前提：有合同到期日数据，能获取客户使用数据

## 工具选型

| 方案                                 | 特点       | 适用        |
| ------------------------------------ | ---------- | ----------- |
| CRM + 脚本                           | 按规则提醒 | ✅ 方案采用 |
| 客户成功平台（Gainsight、ChurnZero） | 健康度评分 | 外企常用    |
| BI 看板                              | 可视化     | 数据团队    |
| Excel 合同台账                       | 现状       | 容易遗漏    |

先用到期提醒 + 使用量下降两条规则覆盖大部分流失；规模大了再上客户健康度评分。

## 怎么做

- 每天检查合同到期日，60、30、7 天各提醒一次客户经理
- 每周对比每个客户近 30 天和前 30 天的活跃用户数、调用量，下降超过 30% 标为流失风险
- 风险客户推给客户经理，附使用量趋势，提前做回访
- 续约结果回写 CRM，统计续约率

## 实施步骤

| 步骤 | 做什么                 | 怎么验证           |
| ---- | ---------------------- | ------------------ |
| 1    | 整理合同到期日到 CRM   | 台账完整           |
| 2    | 接入产品使用数据       | 能按客户统计使用量 |
| 3    | 实现到期提醒和流失规则 | 历史数据回放验证   |
| 4    | 风险客户推送给客户经理 | 附使用趋势         |
| 5    | 续约结果回写并统计     | 有续约率报表       |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
for c in customers:
    days = (c.contract_end - today).days
    if days in (60, 30, 7):
        notify(c.csm, f"{c.name} 合同 {days} 天后到期")
    recent, before = usage(c, 0, 30), usage(c, 30, 60)
    if before and recent / before < 0.7:
        flag_risk(c, f"近 30 天使用量下降 {1 - recent / before:.0%}")
```

## 效果指标

| 指标       | 做之前   | 预期效果（估算） |
| ---------- | -------- | ---------------- |
| 到期才发现 | 常见     | 提前 60 天       |
| 流失信号   | 发现不了 | 使用量下降预警   |
| 续约率     | 不统计   | 按月统计         |

续约提前推进，流失风险客户在到期前被发现。

## 常见坑

- **季节性业务被误判为流失**：使用量本来就有淡旺季。和去年同期比较。
- **客户经理离职，提醒无人接收**：负责人没更新。离职交接时转移客户。
- **只看使用量**：客户满意度也重要。结合工单数量、投诉情况。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：综合使用量、工单、沟通记录判断流失风险并给出挽留建议
- **不该交给 AI**：到期提醒规则确定
- **怎么落地**：AI 给风险客户写分析和挽留建议

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会每天检查合同到期日，到期前 60、30、7 天提醒客户经理；每周对比客户近 30 天和前 30 天的使用量，下降超过 30% 标为流失风险并附趋势图，让客户经理提前回访。续约结果回写 CRM 统计续约率。

常见追问：

**问：客户成功和销售的区别？**

答：销售负责签单，客户成功负责客户用好产品、续约和增购。

**问：什么是客户健康度？**

答：综合使用量、活跃度、工单、满意度、付款情况的评分，用来预测续约。

**问：为什么提前 60 天？**

答：B2B 续约要走采购流程，太晚来不及；也给挽回流失留时间。

**被问到「能不能用 AI」时：** 到期提醒是规则，AI 帮客户经理分析流失原因和挽留方向。
