## 问题

小机房空调坏了、停电了，往往要等服务器宕机或第二天上班才发现，硬件损坏、数据丢失。

## 适用场景

- 适合：有自建机房或服务器间的公司
- 不值得：全部上云、没有本地服务器的
- 前提：传感器和 UPS 有网络接口（SNMP），或者 UPS 能通过 USB 接到一台服务器

## 工具选型

| 方案                       | 特点                   | 适用        |
| -------------------------- | ---------------------- | ----------- |
| snmp_exporter + Prometheus | 和现有监控统一         | ✅ 方案采用 |
| NUT（Network UPS Tools）   | UPS 状态和联动关机     | 开源        |
| UPS 厂商软件（APC、山特）  | 品牌专用               | 常见        |
| 动环监控系统               | 机房专用，含门禁、漏水 | 大机房      |

传感器和 UPS 接入 Prometheus，告警和服务器统一；NUT 负责断电时的有序关机。

## 怎么做

- 网络型温湿度传感器和 UPS 网卡都支持 SNMP，用 snmp_exporter 采集到 Prometheus
- 没有网卡的 UPS 用 USB 接一台服务器，用 NUT（Network UPS Tools）读取状态并对外提供
- 告警：温度 > 30℃、湿度超范围、市电断开、电池电量 < 50%；严重告警同时打电话
- UPS 电量低于 20% 时 NUT 通知所有服务器按顺序安全关机（先业务、后存储）

## 实施步骤

| 步骤 | 做什么                             | 怎么验证                       |
| ---- | ---------------------------------- | ------------------------------ |
| 1    | 安装网络温湿度传感器，接入 SNMP    | 能读到温度                     |
| 2    | UPS 接入（网卡 SNMP 或 USB + NUT） | 能读到供电状态和电量           |
| 3    | 配置告警：温度、市电、电量         | 模拟断电时告警                 |
| 4    | 严重告警走电话                     | 值班人接到电话                 |
| 5    | NUT 有序关机演练                   | 电量低于阈值时服务器按顺序关机 |

## 关键代码

示例代码（简化），没有在生产环境运行：

```yaml
- alert: UpsOnBattery
  expr: upsOutputSource == 5 # 5 = 电池供电
  for: 1m
  labels: { severity: critical }
  annotations:
    summary: 机房市电中断，UPS 正在用电池供电
```

## 效果指标

| 指标         | 做之前       | 预期效果（估算）  |
| ------------ | ------------ | ----------------- |
| 空调故障发现 | 服务器宕机后 | 温度超 30℃ 即告警 |
| 停电时       | 突然断电     | 有序关机          |
| 机房状态     | 靠人巡检     | 实时可见          |

机房问题第一时间知道，停电时服务器有序关机，不会因为突然断电损坏数据。

## 常见坑

- **关机顺序错误**：存储先关导致虚拟机异常。先关业务虚拟机，再关宿主机，最后关存储。
- **UPS 电池老化，实际续航远低于标称**：电池几年没换。定期做电池自检，记录续航时间。
- **监控服务器自己也在断电范围内**：告警发不出去。监控服务器和网络设备接在 UPS 上，或者用外部拨测。

## AI 视角

**⚙️ 规则就够**

- **AI 能做什么**：基本不需要
- **不该交给 AI**：断电关机顺序必须确定
- **怎么落地**：保持规则

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会把机房的网络温湿度传感器和 UPS 网卡都接入 Prometheus，告警规则覆盖温度超过 30℃、市电断开、电池电量低于 50%，严重告警同时打电话。没有网卡的 UPS 用 USB 接到一台服务器，用 NUT 读取状态；电量低于 20% 时通知所有服务器按顺序安全关机，先业务后存储。

常见追问：

**问：UPS 的在线式和后备式有什么区别？**

答：在线式始终由逆变器供电，切换零时间；后备式平时市电直供，停电时切换，有几毫秒间隔。机房用在线式。

**问：机房温度一般控制在多少？**

答：一般 18～27℃，湿度 40%～60%。

**问：NUT 怎么让多台服务器关机？**

答：一台作为主机连接 UPS，其他服务器作为客户端通过网络监听，收到低电量信号后执行关机。

**被问到「能不能用 AI」时：** 机房告警和断电关机必须确定，不用 AI。
