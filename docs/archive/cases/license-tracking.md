## 问题

买了 50 套 Office、装了 70 台，审计时有侵权风险；另一边有设计软件买了却几个月没人打开，续费时也不知道该续多少。

## 适用场景

- 适合：采购了较多商业软件、面临正版化检查或想控制软件费用的公司
- 不值得：主要使用免费软件的
- 前提：有采购台账，能获取电脑的已装软件清单

## 工具选型

| 方案                     | 特点         | 适用        |
| ------------------------ | ------------ | ----------- |
| 脚本 + 资产盘点数据      | 零成本       | ✅ 方案采用 |
| Snipe-IT 许可证模块      | 开源         | 自建        |
| Flexera / ServiceNow SAM | 软件资产管理 | 大型企业    |
| SaaS 管理平台（如 Zylo） | 订阅制软件   | 外企        |

复用资产盘点采集到的已装软件，和采购台账对比，就能回答超装和闲置两个问题。

## 怎么做

- 采购台账记录每个软件的授权数量、授权方式（按人/按设备）和到期日
- 已装软件数据直接来自电脑资产盘点；使用情况从软件的最近运行时间或订阅后台导出
- 按软件对比：安装数 > 授权数的标红（合规风险）；90 天未使用的列为可回收
- 续费前一个月自动生成报告：建议续费数量 = 实际在用人数

## 实施步骤

| 步骤 | 做什么                               | 怎么验证               |
| ---- | ------------------------------------ | ---------------------- |
| 1    | 整理采购台账：数量、授权方式、到期日 | 台账覆盖主要商业软件   |
| 2    | 从资产数据提取已装软件               | 能统计每个软件的安装数 |
| 3    | 获取最近使用时间                     | 订阅后台导出或本机记录 |
| 4    | 对比生成超装和闲置清单               | 有两份清单             |
| 5    | 续费前一个月生成建议                 | 续费数量有依据         |

## 常见坑

- **同一软件多个版本名称不同**：安装记录里的名称不统一。维护软件名称映射表。
- **按人授权和按设备授权混算**：授权方式不同。台账里写清授权方式，分开计算。
- **免费版和商业版混在一起**：同名软件。用版本或产品 ID 区分。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：识别同一软件的不同名称，提高匹配准确率
- **不该交给 AI**：授权数量统计必须准确
- **怎么落地**：AI 辅助做软件名称归一化，人确认映射

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会把采购台账（授权数量、按人还是按设备、到期日）和资产盘点采集到的已装软件对比：安装数超过授权数的标红，这是正版化风险；90 天没使用的列为可回收。续费前一个月自动生成报告，建议续费数量等于实际在用人数。

常见追问：

**问：软件授权有哪些常见方式？**

答：按用户、按设备、按并发、按核心数（服务器软件）、订阅制。

**问：正版化检查查什么？**

答：安装数量是否超过授权、是否有破解版、授权凭证是否齐全。

**问：怎么控制软件成本？**

答：回收闲置授权、选择合适的授权方式、统一采购谈判、用开源替代。

**被问到「能不能用 AI」时：** AI 帮做软件名称归一化，统计本身用规则。
