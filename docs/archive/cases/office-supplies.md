## 问题

办公用品放在柜子里随便拿，用完了才发现没货；年底不知道各部门用了多少，预算没依据。

## 适用场景

- 适合：几十人以上、办公用品统一采购管理的公司
- 不值得：几个人的小办公室
- 前提：行政愿意线上管理

## 工具选型

| 方案                    | 特点                  | 适用     |
| ----------------------- | --------------------- | -------- |
| 飞书 / 企业微信多维表格 | 零代码，表单 + 自动化 | 国内常用 |
| 宜搭、简道云            | 低代码                | 国内     |
| Excel 台账              | 现状                  | 容易乱   |
| 采购平台（京东企业购）  | 直接下单              | 国内常用 |

多维表格 + 表单就能实现，零开发；采购环节可以对接企业采购平台。

## 怎么做

- 物品清单和库存放在多维表格，员工通过表单申领
- 行政确认发放后自动扣减库存，并记录领用人和部门
- 低于安全库存时提醒行政采购，附近 3 个月用量作为采购数量参考
- 每月按部门统计领用量和金额

## 实施步骤

| 步骤 | 做什么             | 怎么验证         |
| ---- | ------------------ | ---------------- |
| 1    | 建物品清单和库存表 | 行政录入现有库存 |
| 2    | 配置申领表单       | 员工能提交申领   |
| 3    | 发放后自动扣库存   | 库存实时准确     |
| 4    | 低库存提醒         | 行政收到提醒     |
| 5    | 月度统计           | 按部门出报表     |

## 效果指标

| 指标     | 做之前 | 预期效果（估算） |
| -------- | ------ | ---------------- |
| 断货     | 常见   | 提前采购         |
| 领用记录 | 没有   | 每次都有         |
| 部门用量 | 不知道 | 月度统计         |

办公用品不再断货，领用有记录，部门用量有数据。

## 常见坑

- **库存和实物不一致**：有人直接从柜子拿。定期盘点，常用小件放开放区单独管理。
- **申领流程太繁琐**：每支笔都要申请。低值易耗品放开放区，只管理贵重物品。
- **采购建议不准**：季节性用量变化。按近 3 个月平均并允许手动调整。

> 我会把办公用品清单和库存放在多维表格里，员工通过表单申领，行政确认发放后自动扣库存并记录部门；低于安全库存时提醒行政，附近 3 个月平均用量作为采购参考；每月按部门统计用量。低值易耗品放开放区不走流程，只管理贵重物品。

常见追问：

**问：什么样的东西需要申领管理？**

答：单价较高或容易流失的（耳机、移动硬盘、显示器配件）；笔和纸这类低值易耗品放开放区更高效。

**问：安全库存怎么定？**

答：按平均用量和采购到货时间计算。

**问：为什么要按部门统计？**

答：给预算提供依据，发现异常用量。
