## 问题

文员每天早上花 1～2 小时从几个系统导数据、粘贴到 Excel、做透视表，再发给领导。一旦请假报表就断了。

## 适用场景

- 适合：每天、每周有固定报表，数据来自多个系统的团队
- 不值得：BI 系统已经覆盖的报表
- 前提：数据源能自动获取（数据库、导出目录、接口）

## 工具选型

| 方案                       | 特点                  | 适用                     |
| -------------------------- | --------------------- | ------------------------ |
| Python + pandas + openpyxl | 灵活，保留 Excel 格式 | ✅ 方案采用              |
| Power BI / 帆软 FineReport | 专业 BI，可视化强     | 外企 Power BI / 国内帆软 |
| Excel Power Query          | 不写代码              | 业务人员                 |
| Metabase / Superset        | 开源 BI               | 自建                     |

管理层习惯看 Excel、要保留公司格式时用 openpyxl 填模板；需要交互分析时上 BI。

## 怎么做

- 定时任务每天 07:30 运行：从数据库查昨日数据，读取各部门共享目录里的 Excel
- pandas 清洗（统一日期格式、去重、对齐门店名称）后计算日、周、月指标和同比环比
- openpyxl 填入预先设计好的模板（保留公司格式），生成柱状图；异常指标（如下降超过 20%）标红
- 用 SMTP 发给收件人列表；数据源缺失时发「今日报表延迟」通知而不是发错的报表

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
sales = pd.read_sql("SELECT store, amount, sold_at FROM orders WHERE sold_at >= %s", conn, params=[yday])
daily = sales.groupby("store")["amount"].sum()
wb = load_workbook("template.xlsx")
ws = wb["日报"]
for i, (store, amt) in enumerate(daily.items(), start=3):
    ws.cell(i, 1, store); ws.cell(i, 2, float(amt))
wb.save(f"日报-{yday:%Y%m%d}.xlsx")
```

## 常见坑

- **数据源缺失时发出错误报表**：某个部门的文件没放。检查数据完整性，不完整就发延迟通知。
- **用 openpyxl 保存后公式和格式丢失**：新建工作簿而不是加载模板。加载模板后只写数据单元格。
- **数字被存成文本**：原始数据格式混乱。读取时统一转换类型。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：给报表写一段「今天发生了什么」的文字解读，回答管理层的追问
- **不该交给 AI**：报表数字必须来自确定的计算
- **怎么落地**：数字由脚本算，AI 只写解读，数字引用必须和表格一致

常见追问：

**问：pandas 合并多个表用什么？**

答：merge（按键关联，类似 SQL JOIN）和 concat（上下拼接）。

**问：为什么用模板而不是从零生成 Excel？**

答：保留公司的格式和样式，业务人员可以自己改模板。

**问：报表自动化最重要的是什么？**

答：口径一致和数据完整性检查，宁可延迟也不要发错误数据。

**被问到「能不能用 AI」时：** 报表数字用脚本算准，AI 写文字解读；我会检查解读里的数字和表格一致。
