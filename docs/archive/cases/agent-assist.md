## 问题

FAQ 机器人能挡住简单问题，但转到人工的工单还是要客服一条条看：先判断是什么问题、该谁处理、急不急，再去知识库翻答案、组织语言。新客服不熟悉产品，回复慢还容易答错；愤怒的客户和普通咨询混在一起排队，等久了直接投诉。

## 适用场景

- 适合：每天几百个以上人工工单的客服团队；产品复杂、新人上手慢的
- 不值得：工单很少、客服能一个个仔细处理的
- 前提：有工单系统；有产品知识库或历史优质回复

## 工具选型

| 方案                                        | 特点                     | 适用        |
| ------------------------------------------- | ------------------------ | ----------- |
| 工单系统自带 AI（Zendesk AI、Intercom Fin） | 开箱即用                 | 外企常用    |
| 国产客服平台 AI（智齿、网易七鱼、晓多）     | 中文场景、电商集成       | 国内常用    |
| 自写：工单 Webhook + 大模型 + 知识库检索    | 可定制分类体系和回复风格 | ✅ 方案采用 |
| 纯人工                                      | 现状                     | 慢          |

已有客服平台的优先用平台自带的 AI；分类体系和回复风格特殊、或需要接内部系统查订单的，自写一层。

## 怎么做

- 新工单进来时触发 Webhook，交给 AI 分析：
  - **分类**：按公司的分类体系（账号、支付、物流、退款、技术故障…），决定分给哪个组
  - **紧急度和情绪**：识别「第三次联系」「要投诉」「愤怒」等信号，情绪激烈的标红并提到队列前面
  - **信息提取**：订单号、手机号、问题描述，自动查询订单状态附在工单里
- 从知识库和历史优质回复里检索相关内容，起草一份回复，附上引用来源
- 客服看到的是：分类、情绪标签、订单信息、回复草稿；修改后一键发送
- 客服修改的部分回流，用于改进知识库和提示词

示例代码（简化），没有在生产环境运行：

```python
@app.post("/ticket-created")
def on_ticket(t: Ticket):
    a = llm.complete(TRIAGE_PROMPT.format(categories=CATEGORIES, text=t.text), response_format=TRIAGE_SCHEMA)
    order = orders.get(a.order_id) if a.order_id else None
    refs = kb.search(t.text, top_k=5)
    draft = llm.complete(REPLY_PROMPT.format(ticket=t.text, order=order, refs=refs, tone=BRAND_TONE))
    helpdesk.update(t.id, group=a.category_group, priority="urgent" if a.sentiment == "angry" else a.priority,
                    tags=[a.category, a.sentiment], internal_note=draft, sources=refs)  # 草稿只是内部备注
```

## 常见坑

- **草稿直接发出去**：客服图省事不看就发，答错了。草稿放在内部备注，发送必须人确认。
- **AI 承诺了做不到的事**：「我们会全额退款」。提示词里禁止承诺，涉及退款、赔偿的用固定话术和审批流程。
- **知识库过时**：回复引用的是旧政策。知识库有负责人和更新流程，回复附来源便于发现。
- **情绪识别误判**：直率的表达被当成愤怒。情绪只影响排序，不影响回复内容。

## AI 视角

**🤖 AI 是核心**

- **AI 能做什么**：理解客户的自然语言、分类、识别情绪、从知识库找答案、起草语气得体的回复
- **不该交给 AI**：发送决定、退款赔偿等承诺、处理极端投诉
- **怎么落地**：AI 做分析和草稿，客服审核发送；和 FAQ 机器人配合，机器人挡简单问题，坐席辅助提高人工效率

常见追问：

**问：坐席辅助和 FAQ 机器人有什么区别？**

答：机器人直接回答客户，适合简单标准的问题；坐席辅助帮人工客服提效，适合复杂问题，最终由人回答。

**问：怎么防止 AI 答错？**

答：回复基于知识库并附来源；禁止承诺；必须人确认才发送；客服的修改回流改进。

**问：怎么衡量效果？**

答：平均处理时长、首次解决率、草稿采纳率、客户满意度。

**被问到「能不能用 AI」时：** 这个案例本身就是 AI；AI 起草，客服把关。
