## 问题

客户的工单被遗忘在队列里，三天没人回复，客户直接投诉到老板；客服主管不知道哪些工单快超时了。

## 适用场景

- 适合：有客服或技术支持团队、对客户有服务承诺的公司
- 不值得：工单很少、一个人能盯住的
- 前提：工单在系统里流转（不是散落在微信群）

## 工具选型

| 方案                                         | 特点               | 适用        |
| -------------------------------------------- | ------------------ | ----------- |
| 工单系统自带 SLA（Zendesk、Freshdesk、智齿） | 开箱即用           | 国内外都有  |
| Jira Service Management                      | SLA 规则强大       | 外企常用    |
| 自写检查脚本                                 | 补充系统没有的规则 | ✅ 方案采用 |
| 表格 + 人工盯                                | 现状               | 容易遗漏    |

工单系统自带 SLA 的直接配置；没有或规则不够时用脚本补充。

## 怎么做

- 按客户等级和问题类型设优先级，每个优先级有响应和解决时限（如 P1：1 小时响应、4 小时解决）
- 每 10 分钟检查一次，剩余 20% 时间时提醒处理人
- 超时自动升级给主管，必要时重新分配
- 每周统计各优先级的 SLA 达成率、平均处理时长，找出瓶颈

## 实施步骤

| 步骤 | 做什么                   | 怎么验证           |
| ---- | ------------------------ | ------------------ |
| 1    | 定义优先级和时限         | 和客户承诺一致     |
| 2    | 工单创建时自动设置优先级 | 按客户等级自动设置 |
| 3    | 配置快超时提醒           | 处理人收到提醒     |
| 4    | 配置超时升级             | 主管收到升级       |
| 5    | 每周 SLA 报表            | 有达成率趋势       |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
SLA = {"P1": (60, 240), "P2": (240, 1440), "P3": (1440, 4320)}   # 响应、解决（分钟）
for t in tickets.open():
    respond, resolve = SLA[t.priority]
    limit = resolve if t.responded else respond
    used = (now - t.created_at).total_seconds() / 60
    if used > limit:
        escalate(t, to=t.team_lead)
    elif used > limit * 0.8:
        remind(t.assignee, t)
```

| 指标     | 做之前           | 预期效果（估算） |
| -------- | ---------------- | ---------------- |
| 工单超时 | 经常发生         | 提前提醒         |

## 常见坑

- **时限没考虑工作时间**：夜间和周末也计时。按工作时间计算，P1 除外。
- **等待客户回复也计时**：责任不在客服。等待客户时暂停计时。
- **升级后没人处理**：只是通知。升级时重新分配处理人。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：自动判断工单紧急程度和情绪，生成回复草稿
- **不该交给 AI**：SLA 计时和升级规则确定
- **怎么落地**：AI 给工单打紧急度和情绪标签，客服用回复草稿

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会按客户等级和问题类型给工单定优先级，每个优先级有响应和解决时限，比如 P1 一小时响应、四小时解决；每 10 分钟检查一次，用掉 80% 时间时提醒处理人，超时自动升级给主管并重新分配；等待客户回复时暂停计时。每周统计 SLA 达成率。

常见追问：

**问：SLA、SLO、OLA 的区别？**

答：SLA 是对客户的承诺，SLO 是内部目标，OLA 是内部团队之间的约定。

**问：工单优先级怎么定？**

答：影响范围和紧急程度两个维度，加上客户等级。

**问：如何提高首次解决率？**

答：知识库、工单分类准确、复杂问题一开始就分给专家。

**被问到「能不能用 AI」时：** SLA 是规则，AI 帮识别客户情绪激动的工单优先处理。
