## 问题

财务每天从邮箱里一封封下载回单和对账单，重命名后拖到对应文件夹；漏存、存错的情况经常发生。

## 适用场景

- 适合：每天收到大量回单、对账单、订单附件的财务、商务部门
- 不值得：邮件量很小的
- 前提：邮箱支持 IMAP，能创建应用专用密码

## 工具选型

| 方案           | 特点                         | 适用        |
| -------------- | ---------------------------- | ----------- |
| Python + IMAP  | 零成本                       | ✅ 方案采用 |
| Outlook 规则   | 只能移动邮件，不能重命名附件 | 简单分类    |
| Power Automate | 微软生态，拖拽               | 外企常用    |
| RPA            | 模拟人工下载                 | 国内常用    |

Python 能按规则下载、重命名、归档附件，处理标记防止重复，邮件客户端规则做不到。

## 怎么做

- 规则表：发件人域名或主题关键字 → 文件类型 → 归档目录（如「招商银行 → 回单 → 财务/回单/2026-10」）
- 脚本每 10 分钟用 IMAP 读取未处理的邮件，按规则下载附件，统一命名为「日期_对方_类型_原文件名」
- 处理过的邮件打上标签，不会重复处理；匹配不到规则的发到人工处理清单
- 账号用应用专用密码，只给邮箱读取权限

## 实施步骤

| 步骤 | 做什么                                  | 怎么验证               |
| ---- | --------------------------------------- | ---------------------- |
| 1    | 整理规则表：发件人/关键字 → 类型 → 目录 | 规则覆盖主要来源       |
| 2    | 应用专用密码，只读邮箱                  | 脚本能读取邮件         |
| 3    | 下载附件、重命名、归档                  | 共享盘按日期和类型归档 |
| 4    | 处理后打标签                            | 重复运行不重复下载     |
| 5    | 未匹配的进人工清单                      | 人工处理剩余的         |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
with IMAPClient(HOST, ssl=True) as box:
    box.login(USER, APP_PASSWORD)
    box.select_folder("INBOX")
    for uid in box.search(["UNKEYWORD", "archived"]):
        msg = email.message_from_bytes(box.fetch([uid], ["RFC822"])[uid][b"RFC822"])
        save_attachments(msg, rule_for(msg))
        box.add_flags([uid], ["archived"])
```

## 常见坑

- **附件文件名乱码**：编码是 RFC 2047 格式。用 email.header.decode_header 解码。
- **同名文件覆盖**：不同邮件的附件同名。文件名加日期和序号。
- **邮箱密码泄露风险**：脚本里写明文密码。用应用专用密码并放在密钥管理里。

常见追问：

**问：IMAP 和 POP3 的区别？**

答：IMAP 邮件留在服务器上、多端同步、支持文件夹和标签；POP3 一般下载到本地。

**问：怎么避免重复处理？**

答：给处理过的邮件打 IMAP 标签，或者记录 Message-ID。

**问：中文附件名为什么会乱码？**

答：邮件头用 RFC 2047 编码（=?UTF-8?B?...?=），需要解码。

**被问到「能不能用 AI」时：** 规则先归档，AI 处理规则覆盖不到的邮件。
