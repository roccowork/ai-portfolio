## 问题

部门花钱时不知道还剩多少预算，到年底一算已经超支；或者年底突击花钱把预算用完。

## 适用场景

- 适合：有年度预算管理的中型以上公司
- 不值得：没有预算制度的小公司
- 前提：预算和实际支出按同样的部门、科目口径记录

## 工具选型

| 方案               | 特点             | 适用        |
| ------------------ | ---------------- | ----------- |
| ERP 预算模块       | 和账务一体       | 国内外都有  |
| 费控系统预算控制   | 申请时就占用预算 | 国内常用    |
| Python + 企业微信  | 按自己的规则预警 | ✅ 方案采用 |
| Anaplan / Adaptive | 预算规划平台     | 外企常用    |

有费控系统的在申请环节就控制预算；没有的用定期对比预警。

## 怎么做

- 预算按部门、科目、月份录入
- 每周从 ERP 和费控系统取实际支出（含已审批未付款的），计算执行率
- 执行率超过时间进度 20%、或者科目预算用到 80% 时预警部门负责人，超支时通知财务
- 每月生成预算执行报表，和月结报表一起给管理层

## 实施步骤

| 步骤 | 做什么                     | 怎么验证           |
| ---- | -------------------------- | ------------------ |
| 1    | 预算按部门、科目、月份录入 | 和财务预算表一致   |
| 2    | 取实际和已占用支出         | 数据口径一致       |
| 3    | 计算执行率和时间进度       | 测试数据正确       |
| 4    | 配置预警规则               | 接近超支时收到提醒 |
| 5    | 月度执行报表               | 管理层每月看到     |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
elapsed = (today - year_start).days / 365
for b in budgets:
    used = actual(b.dept, b.account) + committed(b.dept, b.account)   # 实际 + 已审批未付
    rate = used / b.amount
    if rate >= 1:
        notify([b.owner, finance], f"{b.dept} {b.account} 已超预算 {rate - 1:.0%}")
    elif rate >= 0.8 or rate > elapsed + 0.2:
        notify(b.owner, f"{b.dept} {b.account} 预算已用 {rate:.0%}（时间进度 {elapsed:.0%}）")
```

## 效果指标

| 指标         | 做之前   | 预期效果（估算） |
| ------------ | -------- | ---------------- |
| 超支发现     | 年底     | 实时预警         |
| 突击花钱     | 常见     | 按进度可见       |
| 预算执行报表 | 手工整理 | 自动             |

超支在发生前就被看见，预算真正起到控制作用。

## 常见坑

- **只看已付款忽略已审批**：实际承诺的支出更多。把已审批未付款也计入。
- **季节性支出被误判**：预算按年平均摊。预算按月份分配。
- **部门调整后口径对不上**：组织架构变了。部门映射表随组织调整更新。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：预测年底预算执行情况
- **不该交给 AI**：执行率计算确定
- **怎么落地**：AI 预测附在月度报告里

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会每周把各部门实际支出、加上已审批未付款的承诺支出，和按月分配的预算对比；执行率超过时间进度 20%、或者科目预算用到 80% 时提醒部门负责人，超支时通知财务；每月生成预算执行报表。超支在发生之前就被看见。

常见追问：

**问：为什么要计入已审批未付款？**

答：这部分钱已经承诺要花，只看付款会低估预算使用。

**问：预算控制有哪些方式？**

答：事前控制（申请时检查余额）、事中预警（接近时提醒）、事后分析（报表对比）。

**问：滚动预测是什么？**

答：每月根据实际情况更新全年预测，比一次性年度预算更贴近实际。

**被问到「能不能用 AI」时：** 执行率用规则算，AI 做年底预测。
