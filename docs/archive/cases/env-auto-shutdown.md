## 问题

测试、开发环境晚上和周末没人用，却 24 小时按量计费，常常占云账单的一大块。

## 适用场景

- 适合：测试、开发环境用按量计费云主机的团队
- 不值得：包年包月的机器（关机不省钱）、需要 24 小时运行的环境
- 前提：按量计费，并且支持停机不收费

## 工具选型

| 方案                            | 特点       | 适用        |
| ------------------------------- | ---------- | ----------- |
| 自写脚本 + 云 API               | 按公司规则 | ✅ 方案采用 |
| 云厂商定时开关机                | 控制台配置 | 简单场景    |
| K8s 缩容到 0（kube-downscaler） | 容器环境   | K8s         |
| AWS Instance Scheduler          | 官方方案   | AWS         |

自写脚本：要处理节假日、临时加班和按标签选择，云厂商自带的定时功能做不到。

## 怎么做

- 约定标签：`schedule=office` 的机器只在工作时间运行；不打标签的不动
- 定时任务调云厂商 API 批量关机（选「停机不收费」模式）和开机；节假日用法定节假日表跳过
- 有人临时加班时，在企业微信回复指令或给机器打 `keep-on=今天日期` 标签就跳过当天关机
- 每月统计节省的机时和费用，发给负责人

## 实施步骤

| 步骤 | 做什么                          | 怎么验证           |
| ---- | ------------------------------- | ------------------ |
| 1    | 约定标签 schedule=office        | 测试机都打上标签   |
| 2    | 写脚本：按标签查机器，关机/开机 | 手动运行能正确关开 |
| 3    | 接入节假日表                    | 节假日不开机       |
| 4    | 加班跳过机制（keep-on 标签）    | 打标签当天不关机   |
| 5    | 每月统计节省机时                | 报告发给负责人     |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
for ins in client.describe_instances(tags={"schedule": "office"}):
    if ins.tags.get("keep-on") == today:
        continue
    if action == "stop" and ins.status == "Running":
        client.stop_instance(ins.id)  # 按量实例选「停机不收费」模式
```

| 指标           | 做之前        | 预期效果（估算）                 |
| -------------- | ------------- | -------------------------------- |
| 测试机运行时间 | 每周 168 小时 | 约 50 小时（工作日 08:30–20:00） |
| 费用           | —             | 按量部分约省 60%（估算）         |
| 忘记关机       | 经常          | 自动处理                         |

每台测试机每天少跑约 12 小时，周末全天关机，计算费用约省一半以上（按量计费机型）。

## 常见坑

- **关机后公网 IP 变了**：没有绑定弹性 IP。需要固定 IP 的绑定弹性 IP。
- **早上开机失败没人发现**：库存不足或配额问题。开机后检查状态，失败告警。
- **有状态服务关机后数据异常**：数据库没有正常关闭。关机前先停服务，或者只对无状态机器生效。

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会给测试环境的按量计费机器打 schedule=office 标签，定时任务在工作日 20:00 关机、08:30 开机，节假日按法定节假日表跳过；有人加班就给机器打当天日期的 keep-on 标签。每月统计节省的机时和费用。一周 168 小时变成约 50 小时，按量部分能省一大半。

常见追问：

**问：包年包月和按量计费怎么选？**

答：长期稳定运行的用包年包月或预留实例，间歇使用的用按量；测试环境适合按量 + 定时开关。

**问：停机不收费是什么意思？**

答：按量实例停机后不收计算费用，但磁盘和固定 IP 照常收费。

**问：K8s 测试环境怎么省钱？**

答：非工作时间把 Deployment 缩容到 0，节点自动缩容。

**被问到「能不能用 AI」时：** 定时开关机用规则就够。
