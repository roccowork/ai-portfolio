## 问题

手工记账坚持不了几天；钱花在哪了说不清，月底才发现超支。

## 适用场景

- 适合：想了解自己支出、又坚持不了手工记账的人
- 不值得：已经有习惯的记账方式的
- 前提：愿意每月导出一次账单

## 工具选型

| 方案              | 特点                   | 适用         |
| ----------------- | ---------------------- | ------------ |
| Beancount / Fava  | 纯文本复式记账，可编程 | 技术人员喜欢 |
| 钱迹、随手记      | 记账 App               | 国内常用     |
| Python + Excel    | 自己写规则             | ✅ 方案采用  |
| 银行 App 自带分析 | 只看单一账户           | 简单         |

自己写规则的好处是多个平台统一、分类按自己的习惯；也可以导入 Beancount 做复式记账。

## 怎么做

- 每月从银行、支付宝、微信导出账单 CSV（各平台都支持导出）
- 脚本统一格式、去掉内部转账（避免重复计算），按商户关键字自动分类：餐饮、交通、购物、房租
- 分不出来的少量记录手工补充分类，规则越积越准
- 生成月度收支报告和分类占比，餐饮等分类超出预算时提醒

## 实施步骤

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
RULES = {"餐饮": ["美团", "饿了么", "餐厅"], "交通": ["滴滴", "地铁", "加油"], "购物": ["淘宝", "京东"]}
def classify(merchant):
    return next((cat for cat, words in RULES.items() if any(w in merchant for w in words)), "未分类")
df = pd.concat([load_alipay(f1), load_wechat(f2), load_bank(f3)])
```

## 常见坑

- **转账被重复计算**：支付宝转到银行卡两边都有记录。识别自己账户之间的转账并排除。
- **退款没抵消**：退款单独一条。按订单号或金额关联退款。
- **账单文件含敏感信息**：随便存放。本地加密保存，不上传第三方。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：给规则分不出来的交易做分类，写月度消费总结
- **不该交给 AI**：金额统计必须确定
- **怎么落地**：AI 给未分类交易建议类别，人确认后加入规则

常见追问：

**问：复式记账是什么？**

答：每笔交易同时记录来源和去向两个账户，借贷平衡，能防止记错，Beancount 就是复式记账。

**问：为什么要去掉内部转账？**

答：从支付宝转到银行卡不是支出，不去掉会重复计算。

**问：这和工作有什么关系？**

答：和财务对账、数据清洗是同样的技能：多来源合并、去重、分类、汇总。

**被问到「能不能用 AI」时：** 金额统计用规则，AI 帮分类剩下的交易。
