## 问题

云账单只有总数，老板问「为什么这个月贵了」答不上来；没人用的磁盘、IP 每个月照样扣钱。

## 适用场景

- 适合：云账单每月几千元以上、多个项目共用一个账号的公司
- 不值得：账单很小、只有一个项目的
- 前提：资源打了项目标签，能导出账单明细

## 工具选型

| 方案                 | 特点             | 适用         |
| -------------------- | ---------------- | ------------ |
| Python + pandas 自写 | 灵活，按公司口径 | ✅ 方案采用  |
| 云厂商成本中心       | 分账、预算告警   | 国内外云都有 |
| OpenCost / Kubecost  | K8s 成本分摊     | 容器环境     |
| FinOps 商业平台      | 多云统一         | 大型企业     |

自写脚本：按公司自己的项目口径汇总、加上闲置资源检查，输出业务方能看懂的 Excel。

## 怎么做

- 要求所有资源打 `project`、`env` 标签（Terraform 统一加），没打标签的单独列出来
- 每月 1 号拉取上月账单明细，pandas 按项目和产品汇总，和上月对比，涨幅超过 20% 的标红
- 顺带扫描闲置资源：未挂载的云盘、未绑定的公网 IP、7 天 CPU 低于 5% 的机器
- 报告发到企业微信，附 Excel 明细

## 实施步骤

| 步骤 | 做什么                        | 怎么验证                              |
| ---- | ----------------------------- | ------------------------------------- |
| 1    | 规定标签：project、env、owner | Terraform 创建的资源都带标签          |
| 2    | 拉取月度账单明细              | 能读出每个资源的费用                  |
| 3    | 按项目汇总并环比              | 涨幅超过 20% 的标红                   |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
df = pd.read_csv(bill_csv)
cur = df.groupby(["project", "product"])["cost"].sum()
report = pd.DataFrame({"本月": cur, "上月": last}).fillna(0)
report["涨幅"] = (report["本月"] / report["上月"].replace(0, pd.NA) - 1).round(3)
report.sort_values("本月", ascending=False).to_excel("cost-2026-10.xlsx")
```

| 指标                 | 做之前     | 预期效果（估算） |
| -------------------- | ---------- | ---------------- |

每个月都能回答「钱花在哪、为什么变多」，闲置资源当月就能清理。

## 常见坑

- **大量费用归到「未分类」**：历史资源没有标签。先补标签，未打标签的单独列出给负责人认领。
- **共享资源不好分摊**：负载均衡、带宽多个项目共用。按流量或固定比例分摊，规则写清楚。
- **预留实例、折扣让单价看不懂**：账单里有摊销。用摊销后的成本口径。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：解读账单：「本月涨了 30%，主要是某项目新增的 GPU 机器」，并给出优化建议
- **不该交给 AI**：金额计算和分摊必须精确
- **怎么落地**：汇总后把数据交给 AI 写解读和建议

> 我会要求所有资源打 project、env、owner 标签，每月 1 号拉取上月账单明细，用 pandas 按项目汇总并和上月对比，涨幅超过 20% 的标红；同时扫描未挂载的云盘、未绑定的公网 IP 和低利用率机器，报告发给各项目负责人。

常见追问：

**问：什么是 FinOps？**

答：让技术、财务、业务一起管理云成本：可见（知道花在哪）、优化（关闲置、买预留）、运营（预算和考核）。

**问：降云成本常用手段？**

答：关闭闲置资源、规格降配、测试环境定时开关、预留实例或节省计划、对象存储分层。

**问：K8s 的成本怎么分摊？**

答：按命名空间的资源请求量分摊节点费用，可以用 OpenCost 计算。

**被问到「能不能用 AI」时：** 成本数据用脚本算准，AI 负责写给老板看的解读和优化建议。
