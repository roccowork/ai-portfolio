## 问题

财务月底才翻台账看谁没付钱，逾期几个月的款项没人跟；销售说「客户说下周付」，然后就没有然后了。

## 适用场景

- 适合：B2B 赊销、账期较长、客户多的公司
- 不值得：现款现货的零售
- 前提：应收台账在财务系统里，有客户的财务联系方式

## 工具选型

| 方案                            | 特点         | 适用        |
| ------------------------------- | ------------ | ----------- |
| ERP 自带催收（用友、金蝶、SAP） | 和账务一体   | 国内外都有  |
| Python + 邮件                   | 按规则提醒   | ✅ 方案采用 |
| 专业应收管理（如 Chaser）       | 外企中小企业 | 外企        |
| Excel 台账                      | 现状         | 容易遗漏    |

ERP 有催收模块的直接用；重点是分级规则和销售联动。

## 怎么做

- 每天从财务系统读取未结清的应收，按到期日计算剩余或逾期天数
- 到期前 7 天自动发邮件提醒客户（附发票和付款信息），到期当天、逾期 1 天再提醒
- 逾期 15 天通知对应销售跟进，逾期 30 天财务主管介入
- 每周生成账龄报表（30/60/90 天以上），回款后自动停止提醒

## 实施步骤

| 步骤 | 做什么                       | 怎么验证               |
| ---- | ---------------------------- | ---------------------- |
| 1    | 整理应收台账和客户财务联系人 | 数据完整               |
| 2    | 设计提醒模板                 | 客户收到的邮件专业得体 |
| 3    | 实现到期和逾期规则           | 测试数据按规则提醒     |
| 4    | 联动销售和财务主管           | 逾期 15、30 天正确升级 |
| 5    | 每周账龄报表                 | 有 30/60/90 天分布     |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
for inv in ar.unpaid():
    days = (today - inv.due_date).days
    if days == -7 or days in (0, 1):
        email(inv.customer.billing_email, template="payment_reminder", invoice=inv)
    elif days == 15:
        notify(inv.sales_owner, f"{inv.customer.name} 逾期 15 天，{inv.amount} 元")
    elif days == 30:
        notify(finance_lead, f"{inv.customer.name} 逾期 30 天，{inv.amount} 元")
```

## 效果指标

| 指标         | 做之前     | 预期效果（估算） |
| ------------ | ---------- | ---------------- |
| 逾期发现     | 月底翻台账 | 每天自动         |
| 平均回款天数 | —          | 预期缩短         |
| 坏账风险     | 发现晚     | 分级提前介入     |

回款更及时，逾期款项有人负责、有账龄数据。

## 常见坑

- **客户已付款仍被催**：回款没及时核销。回款对账后立即核销，发送前再查一次。
- **催收语气得罪客户**：模板太生硬。到期前用提醒口吻，逾期后再逐步加强。
- **部分付款处理不当**：只判断是否付清。按剩余金额提醒。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：按客户关系和逾期情况生成得体的催款邮件
- **不该交给 AI**：逾期判断和升级规则确定
- **怎么落地**：AI 生成邮件草稿，财务确认后发送

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会每天从财务系统读取未结清的应收：到期前 7 天、到期当天和逾期 1 天自动给客户发付款提醒，逾期 15 天通知销售跟进，逾期 30 天财务主管介入；回款核销后自动停止提醒；每周出账龄报表。回款更及时，每笔逾期都有人负责。

常见追问：

**问：什么是账龄分析？**

答：按应收逾期时间分段（30、60、90 天以上）统计，账龄越长坏账风险越高。

**问：DSO 是什么？**

答：应收账款周转天数，衡量回款速度。

**问：为什么要销售参与催收？**

答：销售和客户关系最近，知道客户实际情况；财务负责规则和记录。

**被问到「能不能用 AI」时：** 催收规则确定，AI 帮写语气得体的催款邮件。
