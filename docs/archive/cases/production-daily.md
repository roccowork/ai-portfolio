## 问题

统计员每天早上从几个系统导数、手工汇总生产日报，九点开早会时报表还没出来；数据口径各车间不同。

## 适用场景

- 适合：多产线、多班次的工厂
- 不值得：单一产线、产量很小的作坊
- 前提：产量、质检、停机数据有系统记录

## 工具选型

| 方案                      | 特点                 | 适用        |
| ------------------------- | -------------------- | ----------- |
| MES 自带报表              | 和生产系统一体       | 中大型工厂  |
| Python + Excel / 企业微信 | 按工厂口径           | ✅ 方案采用 |
| 帆软 FineReport           | 国产报表，制造业常用 | 国内常用    |
| Power BI                  | 可视化               | 外企常用    |

MES 报表满足不了口径时用脚本或帆软；关键是统一口径、早会前自动送达。

## 怎么做

- 每天凌晨从 MES 读取各产线、各班次的计划产量和实际产量，从设备系统读取停机时间，从质检系统读取良品数
- 计算计划达成率、良率、停机时长，和前一天、上周同期对比
- 达成率低于 90%、良率低于目标、停机超过 30 分钟的标红，并附主要停机原因
- 7:30 前推送给生产经理和各车间主任，早会直接使用

## 实施步骤

| 步骤 | 做什么                   | 怎么验证           |
| ---- | ------------------------ | ------------------ |
| 1    | 统一达成率、良率口径     | 生产和质量部门确认 |
| 2    | 接入 MES、设备、质检数据 | 三方数据能关联     |
| 3    | 生成日报并标异常         | 和手工报表核对一致 |
| 4    | 定时推送                 | 7:30 前收到        |
| 5    | 收集反馈调整格式         | 早会使用           |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
df = mes.output(day).merge(downtime(day), on=["line", "shift"]).merge(qc(day), on=["line", "shift"])
df["达成率"] = df["实际产量"] / df["计划产量"]
df["良率"] = df["良品数"] / df["实际产量"]
df["异常"] = (df["达成率"] < 0.9) | (df["良率"] < TARGET_YIELD) | (df["停机分钟"] > 30)
```

## 常见坑

- **跨天班次统计错误**：夜班跨两个自然日。按班次而非自然日归属。
- **数据源延迟**：MES 还没同步完。检查数据完整性，不全时标注。
- **只看数字不看原因**：异常没有说明。附主要停机原因和不良类型。

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会每天凌晨从 MES 读取各产线、各班次的计划和实际产量，从设备系统读停机时间，从质检系统读良品数，计算达成率、良率、停机时长并和上周同期对比，异常项标红附主要原因，7:30 前推给生产经理和车间主任，早会直接用。夜班按班次而不是自然日统计。

常见追问：

**问：MES 是什么？**

答：制造执行系统，管理工单、生产过程、质量追溯，介于 ERP 和设备之间。

**问：计划达成率低怎么分析？**

答：看停机原因、缺料、质量问题、人员，结合设备数据定位。

**问：ERP、MES、SCADA 的关系？**

答：ERP 管计划和财务，MES 管车间执行，SCADA 管设备监控。

**被问到「能不能用 AI」时：** 日报数字确定，AI 写异常分析。
