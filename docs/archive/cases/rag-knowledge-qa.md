## 问题

「报销流程是什么」「VPN 怎么连」这类问题每天被问几十遍，答案其实都在文档里，但文档太多没人找得到。

## 适用场景

- 适合：文档多、重复咨询多的公司（HR 制度、IT 手册、产品文档）
- 不值得：文档很少或经常过时的
- 前提：有可用的大模型（云端或私有部署），文档相对规范

## 工具选型

| 方案                      | 特点                     | 适用       |
| ------------------------- | ------------------------ | ---------- |
| Dify / FastGPT            | 国产开源，搭建知识库问答 | 国内常用   |
| LangChain / LlamaIndex    | 开发框架                 | 国内外都用 |
| Microsoft Copilot / Glean | 商业企业搜索             | 外企常用   |
| 飞书、钉钉内置 AI 助手    | IM 自带                  | 国内       |

Dify、FastGPT 能快速搭起来；需要深度定制再用框架开发。

## 怎么做

- 文档按段落切分并向量化存入向量库，文档更新时自动重新导入
- 员工提问时先检索最相关的几个段落，再让大模型只根据这些段落回答，并附上出处链接
- 检索不到相关内容时直接回答「没找到，已转给 IT/HR」，不让模型编造
- 按部门控制可检索的文档范围，敏感文档不入库

## 实施步骤

| 步骤 | 做什么                           | 怎么验证           |
| ---- | -------------------------------- | ------------------ |
| 1    | 收集并整理文档，去掉过时内容     | 文档有负责人       |
| 2    | 切分、向量化、入库               | 能检索到相关段落   |
| 3    | 设计提示词：只依据资料、注明出处 | 测试问题回答准确   |
| 4    | 接入企业微信，按部门控制范围     | 员工能在 IM 里提问 |
| 5    | 收集未命中和差评，补充文档       | 回答质量持续改进   |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
chunks = vector_store.search(question, top_k=5, filter={"dept": user.dept})
if not chunks or chunks[0].score < 0.5:
    return "没有找到相关内容，已转给负责同事。"
context = "\n\n".join(f"[{c.source}] {c.text}" for c in chunks)
answer = llm.chat(system="只根据给定资料回答，资料里没有就说不知道，并注明出处。",
                  user=f"资料：\n{context}\n\n问题：{question}")
```

## 效果指标

| 指标     | 做之前       | 预期效果（估算） |
| -------- | ------------ | ---------------- |
| 重复咨询 | 每天几十次   | 大部分自动回答   |
| 找答案   | 翻文档或问人 | 几秒钟           |
| 答案来源 | 口口相传     | 附出处可核对     |

常见问题秒级回答并附出处，HR 和 IT 少回答重复问题。

## 常见坑

- **模型编造答案**：检索不到时仍然回答。要求只依据资料，检索分数低时直接转人工。
- **答案过时**：文档更新后知识库没同步。文档更新自动触发重新导入。
- **越权看到敏感文档**：检索没有权限控制。按部门过滤，敏感文档不入库。

## AI 视角

**🤖 AI 是核心**

- **AI 能做什么**：理解问题、检索文档、组织答案并附出处
- **不该交给 AI**：敏感文档的访问控制必须由规则保证
- **怎么落地**：见正文

> 我会把公司制度、IT 手册、产品文档切分后向量化存入知识库；员工在企业微信提问时，先检索最相关的几个段落，再让大模型只依据这些段落回答并附出处，检索不到就转给负责的同事，不让模型编造。按部门控制可检索的范围。可以用 Dify 这类开源平台快速搭起来。

常见追问：

**问：什么是 RAG？**

答：检索增强生成：先从知识库检索相关内容，再让模型基于这些内容回答，减少编造、能引用出处。

**问：怎么评估问答效果？**

答：准备一组标准问题和答案，定期跑评测；统计用户反馈和转人工率。

**问：文档太长怎么切分？**

答：按标题和段落切分，块之间保留少量重叠，每块附上来源和标题。

**被问到「能不能用 AI」时：** 这个案例本身就是 AI，关键是只依据资料回答、附出处、控制权限。
