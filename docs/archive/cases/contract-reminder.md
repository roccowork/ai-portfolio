## 问题

需要续期的东西散落在各个部门，过期了才发现：

- **人事**：劳动合同到期忘了续签，可能要支付双倍工资；试用期到了没人评估，默认转正；外籍员工签证过期影响合法用工
- **采购**：供应商许可证过期了还在下单，审计时被指出不合规；食品、医疗器械等行业甚至涉及违法风险
- **行政和 IT**：租赁合同、营业执照、域名、软件授权过期，域名被抢注、软件突然不能用、资质过期影响投标

## 适用场景

- 适合：合同、证照、授权多且分散在不同人手里的公司；受监管行业（食品、医药、建筑）
- 不值得：员工和合同都很少、一个人能记住所有到期日的
- 前提：愿意把所有到期事项统一登记，各类日期准确

## 工具选型

| 方案                                 | 特点                       | 适用        |
| ------------------------------------ | -------------------------- | ----------- |
| HR 系统、SRM 自带提醒                | 和档案一体                 | 已有系统时  |
| 多维表格 + 自动化                    | 飞书、企业微信表格自带提醒 | 国内常用    |
| Python 脚本 + 企业微信               | 多级提醒、升级、自动暂停   | ✅ 方案采用 |
| 合同管理系统（法大大、DocuSign CLM） | 签署、归档、提醒一体       | 中大型企业  |

已有系统的直接用系统自带提醒；没有的用一张台账 + 提醒脚本，关键是分级提醒、逾期升级和「过期自动暂停」这道闸。

## 怎么做

- **统一台账**：名称、类型、到期日、负责人、主管、续期方式。人事数据从 HR 系统读取，供应商资质从 SRM 或采购台账读取，其余登记在一张表里
- **按类型设置提前天数**：

| 类型               | 提前提醒      | 通知谁          |
| ------------------ | ------------- | --------------- |
| 劳动合同、职业资格 | 30 天         | HR + 直属主管   |
| 试用期             | 15 天         | HR + 直属主管   |
| 工作签证           | 60 天         | HR + 本人       |
| 供应商资质         | 30 天         | 采购员 + 供应商 |
| 租赁合同、证照     | 30 / 7 / 1 天 | 行政负责人      |
| 域名、软件授权     | 30 / 7 / 1 天 | IT 负责人       |

- **处理闭环**：负责人在提醒里直接选择处理方式（续签 / 不续签 / 转正 / 已续期），填新到期日后不再提醒；到期仍未处理的升级给主管
- **供应商硬性控制**：到期前自动给供应商发邮件请其更新；资质过期的供应商自动标记为暂停，采购系统里不能再下单
- 本站的证书续期是同一思路的全自动版本：HTTPS 证书由 cert-manager 自动续期

## 实施步骤

| 2    | 核对日期（和合同、证件原件比对）     | 抽查无误                  |

| 6    | 每季度导出到期和处理记录             | 给审计使用                |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
AHEAD = {"劳动合同": [30], "试用期": [15], "工作签证": [60], "供应商资质": [30],
         "证照": [30, 7, 1], "域名": [30, 7, 1], "软件授权": [30, 7, 1]}

for item in ledger.items():  # 合并自 HR 系统、采购台账和登记表
    days = (item.expire_at - today).days
    if item.renewed:
        continue
    if days in AHEAD[item.type]:
        notify(item.owners, f"【到期提醒】{item.name} 的{item.type}将于 {item.expire_at:%Y-%m-%d} 到期")
    elif days < 0:
        notify(item.manager, f"【已逾期】{item.name} 的{item.type}已过期 {-days} 天")
        if item.type == "供应商资质" and item.supplier.status == "active":
            item.supplier.suspend()  # 采购系统不能再下单
```

## 效果指标

| 指标                   | 做之前   | 预期效果（估算）   |
| ---------------------- | -------- | ------------------ |
| 合同、证照过期才发现   | 偶有发生 | 提前按类型提醒     |
| 试用期评估遗漏         | 常见     | 提前 15 天提醒     |
| 资质过期的供应商仍下单 | 偶有发生 | 系统拦截           |
| 审计准备               | 临时整理 | 现成台账和处理记录 |

各部门的到期事项在一张台账里统一管理，避免违法用工赔偿和审计问题。实现成本低，适合作为企业自动化的第一个项目。

## 常见坑

- **台账没人更新**：录入后没人维护。新合同签署、新员工入职、新供应商准入时作为流程的一步登记。
- **负责人离职后提醒无人接收**：负责人写死个人。离职交接时转移负责人，或者用部门。
- **提醒内容泄露个人信息**：员工合同信息发在群里。只私信 HR 和直属主管。
- **暂停后紧急采购受阻**：资质过期期间急需。设审批例外通道并留记录。
- **只提醒一次被忽略**：消息太多。分级提醒并逾期升级。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：从合同扫描件、供应商上传的证件里提取到期日、负责人、经营范围，省去手工录入
- **不该交给 AI**：到期判断、提醒和暂停下单是确定的规则，不需要 AI
- **怎么落地**：上传合同或证件时 AI 提取关键日期，人确认后写入台账

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会把各部门需要续期的东西统一到一张台账：劳动合同和试用期从 HR 系统读，供应商资质从采购台账读，营业执照、域名、软件授权单独登记。按类型设置提前天数，比如合同 30 天、试用期 15 天、签证 60 天，提醒负责人，负责人确认处理并填新日期后停止提醒，逾期升级主管。供应商资质过期会自动暂停下单，这是硬性控制。

常见追问：

**问：劳动合同到期不续签也不终止会怎样？**

答：继续用工超过一个月未签书面合同，可能需要支付双倍工资；具体以当地法律为准。

**问：为什么供应商要自动暂停，而不是只提醒？**

答：提醒可能被忽略，暂停是硬性控制，确保不和资质过期的供应商交易；紧急情况走审批例外通道。

**问：为什么这是适合入门的自动化？**

答：需求明确、数据简单、风险低、效果立竿见影，容易获得业务认可。

**问：员工信息提醒要注意什么？**

答：只发给有权限的人，不在群里发，遵守个人信息保护要求。

**被问到「能不能用 AI」时：** AI 帮从合同和证件里提取到期日，提醒和暂停用规则。
