## 问题

OKR 定完就没人看，季度末才发现大部分目标落后；收集各团队进度要追着人要，汇总成 PPT 要半天。

## 适用场景

- 适合：用 OKR 或 KPI 管理、团队较多的公司
- 不值得：只有一个团队、目标很少的
- 前提：各团队愿意每周更新进度

## 工具选型

| 方案                | 特点     | 适用        |
| ------------------- | -------- | ----------- |
| 飞书 OKR / 钉钉目标 | IM 自带  | 国内常用    |
| 多维表格 + 脚本     | 灵活     | ✅ 方案采用 |
| Lattice / Workboard | OKR 平台 | 外企常用    |
| Excel 手工汇总      | 零成本   | 现状        |

用飞书 OKR 的直接用自带功能；用表格的加一个汇总脚本，重点是自动标出风险项。

## 怎么做

- 各团队负责人每周五在表格里更新每个关键结果的当前值和信心指数
- 周日晚上自动汇总：完成度 = 当前值 / 目标值，和时间进度对比，落后 20% 以上标红
- 生成一页纸：总体进度、落后的目标、信心下降的目标、本周没更新的团队
- 周一早上推送给管理层，周会直接讨论标红项

## 实施步骤

| 步骤 | 做什么             | 怎么验证                           |
| ---- | ------------------ | ---------------------------------- |
| 1    | 统一 OKR 填写表格  | 字段：目标、关键结果、当前值、信心 |
| 2    | 设置每周五更新提醒 | 负责人按时收到提醒                 |
| 3    | 编写汇总和风险规则 | 落后项被正确标出                   |
| 4    | 生成一页纸报告     | 管理层认可格式                     |
| 5    | 周一自动推送       | 周会直接使用                       |

## 关键代码

示例代码（简化），没有在生产环境运行：

```python
elapsed = (today - q_start).days / (q_end - q_start).days
for kr in key_results:
    progress = kr.current / kr.target
    kr.status = "落后" if progress < elapsed - 0.2 else ("有风险" if kr.confidence < 5 else "正常")
stale = [t for t in teams if t.last_update < today - timedelta(days=7)]
```

## 效果指标

| 指标         | 做之前                   | 预期效果（估算） |
| ------------ | ------------------------ | ---------------- |
| 汇总进度     | 半天追人和做 PPT（估算） | 自动             |
| 风险发现     | 季度末                   | 每周             |
| 未更新的团队 | 不知道                   | 自动列出         |

管理层每周一就知道哪些目标有风险，不用等到季度末。

## 常见坑

- **只看完成度忽略时间进度**：季度初完成度低是正常的。和时间进度对比。
- **数字填得随意**：没有核对。关键结果尽量来自系统数据而非手填。
- **报告太长没人看**：把所有目标都列出。只突出风险项。

## AI 视角

**✨ AI 能增强**

- **AI 能做什么**：总结各团队进度的文字更新，提炼风险和需要支持的事项
- **不该交给 AI**：完成度计算必须确定
- **怎么落地**：汇总后 AI 写一页纸的总结段落

## 面试怎么讲

30 秒讲法（方案思路；没有实际落地，面试时如实说明是设计过的方案）：

> 我会让各团队每周五在统一的表格里更新关键结果的当前值和信心指数，周日晚上自动汇总：完成度和时间进度对比，落后 20% 以上标红，信心下降的和没更新的团队也列出来，生成一页纸周一推送给管理层。周会只讨论标红项。

常见追问：

**问：OKR 和 KPI 的区别？**

答：KPI 是考核指标，追求达成；OKR 是目标管理，鼓励有挑战的目标，通常不直接和考核挂钩。

**问：为什么要和时间进度对比？**

答：季度过了一半、完成度 30% 是落后的；只看完成度看不出来。

**问：信心指数有什么用？**

答：提前暴露风险，数字还没落后但负责人已经没信心了。

**被问到「能不能用 AI」时：** AI 帮管理层把几十条进度更新提炼成一段风险总结。
